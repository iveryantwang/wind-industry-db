# 韩国推行政府主导选址，2031 年前划定 25GW 海上风电预备区

**2026-09-02**，由国务总理**韩星淑（Han Sung-sook）**主持的**海上风电发电委员会（Offshore Wind Power Generation Committee）首次会议**通过韩国海上风电选址新制度；reNEWS 于 2026-09-04 报道。

## 制度要点

| 项 | 内容 |
|---|---|
| 新模式 | **政府主导选址**，取代开发商自行选址、自行与居民协商、自行办理许可的旧模式 |
| 预备区规模 | **2031 年前划定 25GW 海上风电预备区** |
| 预期装机 | 由预备区带动**新增约 20GW**，支撑**2040 年累计 45GW** |
| 选址依据 | 风况、环境、渔业活动、海上交通、军事用途；使用覆盖 **301 项海洋空间信息与法规**的海上风电选址信息网 |
| 许可整合 | 规划阶段即与相关部会预审主要许可事项；企业选定后，**42 项许可事项**依《海上风电法》一并处理 |
| 社会接受度 | 由地方政府牵头组建**官民协议体**，自项目早期即与居民、渔业社区协商收益共享与共存措施 |
| 流程 | 预备区划定 → 基本设计与官民协商 → 开发区划定 → 企业选定 → 实施计划批准 → 施工 → 竣工 |
| 时间表 | **年内划定首个预备区**；经基本设计、环境评价、地方政府协商、开发区划定与企业选定后，**最早 2033 年**起进入建设 |
| 委员会构成 | 同时委任 **12 名民间委员**，济州大学教授**金范锡**任民间委员长 |

## 对我方的含义（OEM 视角）

**这是一次「谁来决定项目在哪里」的制度性转移，对整机厂的直接影响是采购时点整体后移、但可预期性大幅提升。**

- **短期（2026–2030）无新增可争取标的。** 首个预备区年内划定，但建设最早 2033 年 —— 意味着未来数年韩国海上的整机订单仍只能来自**已授标的存量项目**（见 [[韩国-2026上半年授标5项目1.78GW]]、[[韩国-PacificoEnergy-Jindo二期2130MW]]、[[韩国-Gochang Offshore-高敞76.2MW]]）
- **中期是一个 20GW 级、且时间表可倒推的池子。** 与越南、柬埔寨那种「等法规但没有刻度」的等待不同，韩国这次给出了明确的阶段划分与年份锚点，可以据此做产能与本地化投入的排期
- **风险在于「企业选定」这一环。** 政府主导选址后，开发商与整机商的绑定关系被推到更靠后的节点，**先与开发商建立关系的传统打法效力下降**，转而需要在预备区划定与基本设计阶段就参与技术输入
- **本地含量压力预计上升。** 政府主导选址通常与产业培育目标绑定；库内 [[P1-韩国1.78GW授标项目拆分与LCR]] 已记录韩国 LCR 倾向，[[Unison-韩国Hanbit 340MW优先供应商与1GW新厂]] 则是本土整机厂借政策扩产的现成样本。**制度越由政府主导，本土厂商的结构性优势越大**
