## 事件

2026-09-08，**Suzlon** 宣布获得 **Ayana Renewable Power Limited** 的**首笔**风电订单，**200MW**，项目位于**中央邦 Limbawas**。

| 项 | 内容 |
|---|---|
| 容量 | 200 MW |
| 机型 | **S144，单机 3.15MW** |
| 台数 | **64 台** |
| 交付范围 | **EPC 总包** —— 整机供货、征地、BOP、汇集升压站、超高压送出线路、调试、运维 |
| 送出 | 接入 MPPCL 州电网 |
| 商业模式 | Suzlon 的 **DevCo** 模式，本单为该模式第三单，横跨中央邦与安得拉邦 |
| 平台累计 | **S144 平台订单突破 10GW** |

Ayana 现有约 **5.5GW** 可再生组合（风、光、RTC），本项目是其**首次进入中央邦风电**。Suzlon 称短期内已在两个邦拿到四笔风电订单。

## 为什么值得记

不在于 200MW，在于**印度整机竞争的形态**：Suzlon 卖的不是风机，是「开发 + 总包 + 运维」的一体化交付，业主选它的理由被明确表述为「技术 + 执行 + 一体化交付」。这与本库对欧洲市场的既有判断（[[整机出海从设备供货到全链条方案]]）同构 —— 印度市场也已越过纯设备供货阶段。
