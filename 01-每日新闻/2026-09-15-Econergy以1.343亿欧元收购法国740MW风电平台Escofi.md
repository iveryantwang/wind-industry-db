## 事件

| 项 | 内容 |
|---|---|
| 买方 | **Econergy Ltd**（欧洲独立可再生发电商，首次进入法国） |
| 标的 | **Escofi**（1988 年创立的法国陆上风电开发运营商） |
| 对价 | **EUR 1.343 亿** |
| 组合 | **740MW**，分四个阶段 |
| ├ 已商运 | 128MW |
| ├ 在建 | 34MW |
| ├ **高级开发** | **147MW —— 已持建设许可与并网批复，2028–2030 开工** |
| └ 早中期开发 | 432MW |
| 区域 | 上法兰西（Hauts-de-France）、大东部（Grand Est） |
| 收入结构 | 逾 90% 已运行及在建容量享法国 **20 年 CfD**；2026-07 另有 3 个合计 46MW 项目中标 CfD，价格高于 EUR 80/MWh |
| 顾问 | Marathon Capital（买方财务）、KPMG（财税）、Linklaters（法律） |
| 持股 | Escofi 对各项目平均有效持股约 91% |

Econergy 同时点名了**存量资产改造（repowering）**方向：已有 1 个改造项目在推进，第 2 个已中标 CfD。

## 为什么记（OEM 视角）

**这是一次「业主换人」事件，对整机厂的意义在于：147MW 已核准管道的整机决策权，昨天从一个 37 年的法国家族式开发商，转到了一个刚进法国、正在建组合的以色列背景 IPP 手里。**

三点判断：

1. **147MW 是整机未定的实盘。** 许可与并网都已到位，2028–2030 开工，整机采购按常规倒推应在 **2027 年上半年**定标 —— 窗口开着，但不长。
2. **买方是新进入者，供应商关系没有历史包袱。** Escofi 原有的机型体系未公开，但 Econergy 在法国没有既有运维体系要迁就，这类买方在首轮采购上通常愿意见新供应商。
3. **改造方向单独成一块。** Escofi 1988 年起家，128MW 存量里相当一部分机龄已长，Econergy 明说要做 repowering 且已有 2 个项目在手 —— 这是法国陆上少见的、由业主主动发起的置换需求。

**同时要看到的约束：** 法国 CfD 体制下的陆上项目报价空间被执行价锁死，且 20 年 CfD 已签的项目对整机的度电成本敏感度极高。这不是一个靠服务溢价能赢的市场。
