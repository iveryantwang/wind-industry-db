## 事件

**2026-09-02**，**ESB**（爱尔兰电力局）宣布苏格兰高地 Lairg 附近 **96MW Chleansaid** 陆上风电场达成 **FID**，完成主要施工合同签署。

| 项 | 内容 |
|---|---|
| 容量 / 台数 | **96MW / 16 台**（推算单机约 6MW） |
| 股权 | ESB **100%** |
| 许可 | 2023 年规划许可 |
| 收入 | **15 年期 CfD** |
| **整机 + 长期服务** | **GE Vernova** |
| 电气 BoP | Kirby Group |
| 土建 BoP | Farrans Construction |
| 开工 / 商运 | 2026 年内 / 2028 |

ESB 可再生能源负责人 Paul Lennon 称这是 ESB 在苏格兰**自主开发的首个**陆上风电项目；Chleansaid 是 ESB 在**苏格兰与威尔士约 2GW** 陆上风电管道中**首个进入建设**的项目。

## 对我方的含义

**96MW 本身不重要，「ESB 约 2GW 管道的首单被 GE Vernova 拿走，且带长协」才重要。**

**这是本月第二次看到国际厂商用「首单 + 长期绑定」锁死一个英国陆上业主。** 第一次是 [[Nordex-EDF英国最高900MW独家供货框架]]（2026-08-05，明面独家框架）。这次是事实性绑定：整机 + LTSA 一起给，业主的运维体系、备件与人员培训随之定型，后续项目换供应商的转换成本被抬高。

**英国陆上对我方的路径正在被逐个业主收口。** 本库 [[P1-英国陆上EDF渠道被Nordex锁定后的替代路径]] 曾把 ESB 一类的新进业主视为替代路径 —— **今天这条替代路径关闭了首个入口，判断需要更新。**

同时要看到留下的缝：**ESB 还有约 2GW 在开发**，Chleansaid 只是第一个。若 GE Vernova 合同不含后续项目优先权，威尔士侧与合资项目仍有机会。**这需要核实，而不是假设。**
