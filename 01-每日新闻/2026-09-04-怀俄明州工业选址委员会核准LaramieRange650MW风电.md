# 怀俄明州工业选址委员会核准 Laramie Range 650MW 风电项目

怀俄明州环境质量署（DEQ）下属**工业选址委员会（ISC）**在为期两天、累计近 18 小时的听证后，核准了 **650MW Laramie Range 风电项目**在私有与州有土地上的建设许可。Windpower Monthly 于 **2026-09-04** 报道，Cowboy State Daily 的现场报道日期为 2026-09-01。

| 项 | 内容 |
|---|---|
| 业主 | ConnectGen Laramie County（Repsol Renewables North America 关联公司） |
| 位置 | 怀俄明州拉勒米县，夏延西北约 20 英里 |
| 规模 | **650MW / 139 台机组 / 约 41,220 英亩** |
| 本次核准占地 | 私有地约 35,350 英亩 + 州有地约 5,870 英亩 |
| 开工 | 预计 2027 年 Q4 |
| 投运 | 分两期，均于 2029 年底前投运 |
| **整机供应商** | **仍未公开** |

**关键背景：** 本次通过 ISC 的方案，**占地范围小于 2025 年 9 月被拉勒米县委员会否决的版本**。县级否决后项目转向州级许可路径，本次获批意味着该路径走通。

按 139 台 / 650MW 反推，单机约 **4.7MW** 级。
