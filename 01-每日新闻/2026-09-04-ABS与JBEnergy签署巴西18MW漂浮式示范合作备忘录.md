# ABS 与 JB Energy 签署巴西 18MW 漂浮式示范项目合作备忘录

美国船级社（ABS）与日本 Japan Blue Energy（JB Energy）于 **2026-09-04** 签署合作备忘录，就巴西首个漂浮式海上风电示范项目 **Aura Sul Wind** 开展战略研究协作。

## 项目要点

| 项 | 内容 |
|---|---|
| 项目名 | Aura Sul Wind |
| 位置 | 巴西南里奥格兰德州（Rio Grande do Sul）里奥格兰德外海约 65 公里 |
| 水深 | 约 44 米 |
| 规模 | **单台 18MW 漂浮式机组** |
| 浮体 | JB Energy **Raijin Float** —— 预应力混凝土半潜式基础，面向巴西本地制造 |
| 整机 | **明阳智能 MySE 18MW** |
| 投资 | 约 **1 亿美元** |
| 投运目标 | 2030 年前 |
| 许可 | 已获巴西环境监管机构 IBAMA 环境许可，为巴西首个获此许可的海上风电项目 |

## ABS 的工作范围

本次备忘录覆盖两个方向：

1. **里奥格兰德港的减排路径研究**
2. **Raijin Float 混凝土浮体的初步退役策略**

## 对我方的含义

**这是一条「已失单 + 技术路线被定义」的双重信号。**

- **整机已定，且被明阳拿下。** 巴西首个漂浮式示范的整机不在我方可争范围，详见 [[明阳智能-巴西AuraSulWind 18MW漂浮式整机供货]]
- **更值得注意的是浮体路线。** Raijin Float 是预应力混凝土半潜式，明确以「利用巴西本地水泥工业、船厂、海工能力与港口基础设施」为设计前提。**混凝土浮体 + 本地制造的组合一旦在巴西跑通，会成为该市场后续项目的默认基准**，我方若只有钢制半潜方案，在巴西的适配论证成本会显著上升
- **18MW 单机是当前全球漂浮式最大机位。** 明阳用一台示范机把「漂浮式最大机型」的公开标签拿走，这对我方在英国 Llŷr、意大利漂浮式管道等标的的技术叙事构成直接压制
