## 事件

**2026-09-03**，**GE Vernova** 确认与 **ESB** 签署 **96MW Chleansaid**（苏格兰高地）陆上风电场整机供货协议。这是对 [[2026-09-02-ESB苏格兰Chleansaid96MW完成FID由GEVernova供货]] 的正式确认与细节补充。

| 项 | 内容 |
|---|---|
| 台数 / 机型 | **16 × Cypress 6.1MW-158m** |
| 制造地 | **德国** |
| 服务 | **20 年服务协议** |
| 特殊配置 | **16 台全部采用分段叶片（split-blade）技术** |
| 里程碑 | **Cypress 平台在英国的首次应用** |
| 平台业绩 | GE Vernova 6MW 级产品全球逾 **1,800 台**、累计运行超 **3,800 万小时** |

GE Vernova 陆上风电国际市场首席商务官 Gilan Sabatier：这是其「主力 6MW 机型」在英国的首次使用，是在既有英国业绩基础上的扩展。
ESB 可再生能源负责人 Paul Lennon：Chleansaid 是 ESB 在苏格兰全资自主开发的首个陆上风电项目。

## 对我方的含义

**真正的新信息不是「GE Vernova 拿了 96MW」（09-02 已知），而是「分段叶片被用来解决苏格兰高地的运输约束」。**

GE Vernova 明确说明：分段叶片技术**使更大叶片能够运抵偏远、道路条件受限的场址，从而允许使用更大风轮**。苏格兰高地、威尔士山区、北欧内陆这一类场址，此前的机型选择被公路运输半径卡住 —— **谁能把大风轮送进去，谁就能在同样的风资源上多发电，报价空间随之打开。**

这条对我方的直接含义：**在英国、爱尔兰、北欧的山地陆上项目上，「运输方案」已经从投标的附件变成了机型竞争力的一部分。** 我方若无分段叶片或等效运输方案（分段塔、模块化叶片、现场组装），在这类场址上会被结构性排除，而不是价格上输掉。

第二点：**机舱德国制造 + 20 年服务** —— 与 [[Vestas-德国EuropeanEnergy Wulfshagen 50MW改造订单]] 同日的配置一致，进一步印证欧洲陆上「本地制造 + 长协」的双门槛。
