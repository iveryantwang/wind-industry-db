## 事件

2026-09-07，Enercon 与 **Qair Group** 达成罗马尼亚 **Cobadin 1** 风电场供货协议：**7 台 E-175 EP5 E2**，含**供货 + 安装 + 长期运维**，2027-07 起交付，2027-08 底首台调试。

**两个「首次」：** Enercon 与 Qair 在罗马尼亚的首次合作；E-175 EP5 E2 平台在罗马尼亚的首次部署。

Enercon CNE 国际销售总监 Toralf Pohl：「罗马尼亚是 Enercon 最重要的增长市场之一……这一成功清楚证明了我们的竞争力，并巩固了我们在这一地区的地位 —— Enercon 在此已建立起强有力的本地布局。」

（**本条为补录，事件日早于上次运行覆盖窗口，补录理由见 [[2026-09-07-Enercon获Qair罗马尼亚Cobadin1整机供货]]。**）

## 对我方的含义

**一、这是 Enercon 的平台落地打法，不是一次孤立成交。**

对照库内 [[Enercon-E175EP5E2标定发电量上调5.5%]] 记录的时间线：

| 时间 | 动作 |
|---|---|
| 2025-09-16 | E-175 发电量升级（首次） |
| 2025-09-22 | E-175 在英国发布 |
| 2026-04-21 | WindEurope 期间取得 **E-175 EP5 认证** |
| **2026-09-04** | **EP5 E2 标定 AEP 再上调 5.5%，额定功率不变** |
| **2026-09-07** | **该平台在罗马尼亚拿下首单（本条）** |

**认证 → 标定上调 → 拿单，三个动作在五个月内走完，最后两步只隔三天。**

**这正是库内 [[不提额定功率的发电量标定上调路径]] 描述的那套打法的完整闭环：不改额定功率、只上调标定发电量，从而在不重新认证的前提下改善业主的度电成本测算，再用改善后的数字去投标。** 09-04 那条当时记的是「路径」，**本条证明这条路径已经变现。**

**给我方的直接问题：我方有没有等效的、可在不重新认证前提下提升标定 AEP 的手段？如果没有，在同一场址上我方的发电量报价就永远比对手低 5.5%。**

**二、「供货 + 安装 + 长期运维」的打包形态，在新兴市场是加分项。**

这与 09-09 [[P2-独立服务商侵蚀存量机组运维的应对]] 得出的分界一致：**欧洲成熟市场的服务是竞标品，新兴市场的服务是壁垒。** 罗马尼亚属于后者 —— Enercon 用长期运维把自己钉在当地，第二笔 50MW 份额与 Qair 的后续项目都会因此更难撬动。

**三、Enercon 自述「在罗马尼亚已建立强有力的本地布局」。**

这是一句需要核实的话，因为它决定我方进入罗马尼亚的门槛是什么。**若「本地布局」指的是服务基地与备件库，那么我方在罗马尼亚面对的是与在意大利面对 Vestas 相同的局面（见 [[P1-意大利中小陆上标的被Vestas连续拿下的渠道补位]]）：不是价格问题，是在位问题。**

**四、但这次失单带回来的东西比丢掉的多。**

Qair 是本库在罗马尼亚与摩尔多瓦拿到的第一个可指名对象，且两国由同一运营主体管理。**详见 [[P1-Qair集团罗马尼亚与摩尔多瓦双市场渠道切入]]。**
