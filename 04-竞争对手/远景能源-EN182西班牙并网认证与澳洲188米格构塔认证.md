# 远景能源 —— EN-182/6.25 获西班牙 NTS 2.1 并网认证；188 米格构塔获澳洲型式认证

## 事实

- **EN-182/6.25MW**：UL Solutions 出具西班牙 **NTS 2.1** 机组级并网合规认证（Grid Code Compliance Unit）
- **Nabralift 3.MAX HH188 格构塔**（配 EN-182/7.8MW）：UL 型式认证，面向澳大利亚市场，**轮毂高 188 米**
- 远景称将扩展到更多机型与其他欧洲国家（[PR Newswire](https://www.prnewswire.com/news-releases/envision-energy-advances-global-wind-market-readiness-with-ul-solutions-certifications-in-europe-and-australia-302892886.html)）

## 对我方的含义

- **不是订单，是准入文件。** 但节奏值得警惕：09-24 汉堡发布 EN175/8.0（欧洲陆上）→ 09-28 EN-206/8.35 获 DNV 型式认证 → 09-29 西班牙并网 + 澳洲高塔认证，**一周三步，远景在系统性补齐欧洲/澳洲陆上的「可投标」资格**
- **西班牙**：本库此前无远景在西班牙的记录；NTS 2.1 是西班牙项目并网前置条件，意味着远景已在为西班牙具体项目投标做准备 —— **对我方在南欧（含意大利）陆上的价格压力将上升**
- **澳大利亚**：远景已有 [[远景能源-澳大利亚Neoen Narrogin 179MW订单]]；188 米格构塔把可开发场址扩展到低风速内陆，**与金风在澳（[[金风科技-澳大利亚Gawara Baya 408MW 68台GW165-6.0订单]]）形成中资双强**
- 与 [[第三方型式认证作为中国整机出海可融资性门槛]] 同一逻辑：中国同行正在把「认证」当作出海的第一道工序
