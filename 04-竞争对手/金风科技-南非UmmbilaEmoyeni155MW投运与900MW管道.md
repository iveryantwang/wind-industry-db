## 事件

2026-07-31，南非总统 Cyril Ramaphosa 出席仪式，Seriti Green 的 **Ummbila Emoyeni 风电场一期 155MW 进入商业运行**。

| 项目 | 口径 |
|---|---|
| 一期容量 | 155MW |
| 机组 | **25 台金风 GWH182-6.2MW** |
| 叶轮直径 | 183.5 米 —— 南非在运风电项目中最大 |
| 年发电量 | 约 525GWh |
| 位置 | 姆普马兰加省 Bethal 与 Morgenzon 之间 |
| 投资 | 约 50 亿兰特 |
| 地位 | 姆普马兰加省首个内陆公用事业级风电场；肯尼亚以南规模最大的并网就绪风电场之一 |

**这不是一个 155MW 的单子，是一条 900MW 的管道：**

- Ummbila 综合体整体规划为 **750MW 风电 + 150MW 光伏 + 800MWh 储能**
- **二期与三期已在建**
- 金风与 Seriti Green **已就四期签署合作协议**
- 一期投运同时，Seriti Green 另签约 100 亿兰特

## 对我方的含义

**这是一次完整的「首单 → 管道锁定」演示，而且是被我方错过的那种。**

Seriti Green 是南非煤炭企业 Seriti Resources 的绿电平台，属于「公正能源转型（Just Energy Transition）」框架下的旗舰角色 —— 政治能见度极高（总统出席），后续管道确定性强。金风的打法是：拿下首个 155MW，用最大叶轮直径建立技术标杆，然后在二、三期在建期间直接锁定四期合作协议。**等我方发现时，750MW 风电已基本无缝可插。**

三点值得记下来：

1. **南非市场我方在库内几乎空白。** 02-客户与项目 板块此前无南非条目，07-战略判断 板块也没有南非线。金风在这个市场已经完成从首单到管道的闭环，我方连开发商名单都没有。这是覆盖缺口，不是竞争失利。
2. **「首单换管道」的模式与我方在柬埔寨的既定打法完全同构。** [[P0-柬埔寨首单示范价值]] 的逻辑就是「以首单示范地位换取后续 900MW 管道优先地位」—— 金风在南非把这套打法执行完了，我方在柬埔寨的同一套打法已经逾期三周未推进。**这条竞对信息的真正用途，是证明那套打法有效，因此柬埔寨的拖延代价是实的。**
3. **大叶轮低风速机型是切入南部非洲内陆的技术条件。** GWH182 的 183.5 米叶轮配 6.2MW 是典型的低风速高切变配置，与我方 [[低风速高切变场址的3.9MW级机型与156米混塔组合]] 的技术路线同类。技术上我方并非不能打，是没在场。

**结论：中国厂商海外订单，`importance: 高`。同时暴露我方南非市场覆盖为零。**
