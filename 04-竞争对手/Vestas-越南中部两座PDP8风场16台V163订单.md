# Vestas —— 越南中部两座 PDP8 风场，16×V163（4MW 平台），约 72MW

## 事实

| 项 | 内容 |
|---|---|
| 计入 | Q3 2026（订单表 09-30，72MW）；新闻稿 10-02 河内 |
| 机型 | 16×**V163**（4MW 平台，约 4.5MW/台），**155m 定制轮毂高度** |
| 服务 | 20 年 AOM 5000 |
| 业主 | 未披露；「越南开发商、项目组合大」；风场「靠近 Vestas 既有项目集群」 |
| 定位 | **PDP8 首批**取得投资许可并进入执行的项目 |
| 交付 | 2027 年开始 |

`importance` 标「高」的理由：Vestas 非中国厂商，但这是**五国重点之一越南**在 PDP8 新周期下的首批公开整机定标，且直接对应我方在库的越南中部陆上管道。

## 对我方的含义

1. **不是在库项目的直接失单，但大概率是同一批客户。** 「越南中部 + 靠近 Vestas 既有集群 + 大型组合开发商」高度指向广治/嘉莱一带（Vestas 在广治有大量 V150 存量）。库内 [[越南-春桥Holdings-Cam Lo 200MW]] 与 [[越南-Phuc Loc Tho 200MW近海风电]] 均在广治，容量（各 200MW）与本单（两座合计 72MW）不符 → **暂不判失单**，但须立即反查
2. **对标基准被抬高**：Vestas 拿 4MW 平台（老平台、低价）+ 155m 高塔 + 20 年全包运维去打低风速场址，这是用「成熟机型 + 塔高」替代「大兆瓦」的打法；我方若以 6–8MW 机型报价，需证明在 PDP8 小项目（30–50MW/座）上的度电成本优势
3. PDP8 首批项目已进入整机定标期，**嘉莱省 Q4 拟开工 24 个风电项目 2,150MW**（见 [[P0-越南中部PDP8陆上项目四季度集中开工前的整机窗口]]），窗口是成批关闭的
