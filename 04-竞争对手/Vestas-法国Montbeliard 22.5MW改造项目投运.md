## 事件

**2026-09-01**，ERG 宣布法国东部 Doubs 省 **Montbéliard** 风电场改造（repowering）项目完工并投运 —— 这是 ERG 在法国完成的**第一个改造项目**。

| 项 | 值 |
|---|---|
| 装机 | **22.5MW** |
| 机组 | **5 台 Vestas V136-4.5MW** |
| 总高（叶尖） | **180 米** |
| 年发电量（估） | 约 **62GWh** |
| 售电机制 | **20 年 CfD** |
| 容量变化 | 较原配置**翻一倍以上** |
| 发电量变化 | 较原配置**接近三倍** |
| 占地 | **不变**，沿用既有基础设施 |

ERG CEO Paolo Merli：本项目使 ERG 在法国的风光累计装机达 **755MW**；改造的价值在于「同时实现机队现代化与长期售电价格稳定」。

## 对我方的含义：改造市场的经济性数字第一次凑齐了

**这条不该按 22.5MW 的规模来读。它的价值在于给出了一组完整的陆上改造经济性参数，而本库此前缺这组数。**

**一、改造的核心杠杆：容量翻倍、发电量近三倍、占地不变。**

发电量增幅（约 3 倍）显著高于容量增幅（约 2 倍），差额来自机型代际 —— 更大风轮（136 米）＋ 更高塔筒（叶尖 180 米）在同一场址上把容量系数拉高了。**这组比例是向业主推销改造方案时最有力的论据，且它是第三方项目的实测值，不是我方测算值。**

62GWh ÷ 22.5MW ≈ **2,756 小时**等效满发（容量系数约 31.5%），在法国内陆场址属较好水平。

**二、「占地不变、沿用既有基础设施」这一条，是改造市场对整机厂的真正门槛。**

沿用既有机位与集电线路，意味着**新机型必须适配旧基础的位置与间距约束** —— 这是改造项目的技术准入条件，不是新建项目的自由选型。V136-4.5MW（4.5MW / 136 米风轮）在当前欧洲陆上产品谱里属于**中等偏小机型**，Vestas 在这里没有上更大机型，恰恰印证了改造场址对机型尺寸有上限约束。

**对我方的直接含义：欧洲改造市场需要的不是我方最大的机型，是「在受限机位上能装进去的最优机型」。** 这与本库 [[荷兰-陆上风电退距标准2倍叶尖高]] 的结论方向一致（该政策亦明确改造项目可豁免退距限制），也与 [[低风速高切变场址的3.9MW级机型与156米混塔组合]] 的产品定位相关。**若我方欧洲陆上产品线只有大兆瓦机型，改造这块市场进不去。**

**三、Vestas 的改造布局在推进，我方无对应记录。**

Vestas 与 ERG 的合作不止本条 —— ERG 于 2025-12 在意大利改造拍卖中拿下 141MW（本库未收录，属背景）。**ERG 是一家同时在意大利、法国、英国持有资产的开发商（法国 755MW、英国 73MW 组合），且其战略明确转向改造。它同时也是 [[P1-意大利FERX首场拍卖前的开发商绑定]] 原名单中的一家。** 本条说明 ERG 在法国已把 Vestas 作为改造供应商 —— 若我方要在意大利接触 ERG，须知道其既有供应商关系。
