## 事件

Nordex 获 **Türkerler Holding** 订单，为土耳其 **YEKA-5 R25 锡瓦斯（Sivas）风电项目**供货并安装：

| 项目 | 内容 |
|---|---|
| 容量 | **525 MW** |
| 机型 | **72 台 N175/6.X**（Delta4000 系列） |
| 轮毂高度 | 108 米 |
| 服务 | 10 年 Premium Service，可展期至 **25 年** |
| 首台安装 | 2027 年三季度 |
| 市场地位 | 该单为**土耳其风电市场史上最大单笔整机合同** |
| Nordex 土耳其累计份额 | 升至 **34%** |

Nordex 土耳其与中东区副总裁 Ender Özatay 强调三点竞争优势：N175/6.X 技术竞争力、**本地供应链**、以及在此前多轮 YEKA 招标中的业绩记录。

## 对我方的含义

**土耳其目前不在本库在库标的范围内，但这一单的三个特征直接映射到我方正在争取的所有市场。**

1. **"国家级 YEKA 拍卖 + 本地供应链 + 超长运维"是同一套打法，Nordex 已在土耳其复制成熟。** 与 [[Nordex-EDF英国最高900MW独家供货框架]]（英国独家框架）、[[Nordex-罗马尼亚Urleasca 77MW订单]]（35 年 Premium Service）完全同构 —— **Nordex 正在系统性地用"长运维锁死全生命周期"关闭市场，而不是单点抢标**
2. **34% 的单国市场份额意味着结构性锁定。** 一旦某国累计份额过三分之一，本地服务网络、备件库、技工队伍的规模效应会形成自我强化，后来者的边际成本劣势难以靠报价弥补。**这正是我方在哈萨克斯坦、老挝、越南面临的同一风险 —— 只是那里的先手方是远景、运达、明阳**
3. **土耳其是中东/中亚陆上市场的枢纽。** Nordex 在土耳其的本地供应链一旦成熟，向哈萨克斯坦、乌兹别克斯坦、阿塞拜疆的辐射成本极低。**我方在中亚的产能本地化布局（参见 [[整机厂机舱产能本地化布局]]、[[P0-哈萨克斯坦本地产能门槛应对]]）应把土耳其纳入竞争半径评估，而非只盯中资同行**
4. **N175/6.X 是本单的主力机型，与我方陆上大兆瓦机型正面重叠。** 108 米轮毂 + 175 米风轮的配置应纳入我方陆上机型比选的对标清单
