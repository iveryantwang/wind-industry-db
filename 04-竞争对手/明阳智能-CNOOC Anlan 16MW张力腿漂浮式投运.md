## 事件

2026-08-07，**明阳智能**宣布其称为「全球首台 16MW 张力腿平台（TLP）漂浮式风电机组」的 **CNOOC Anlan（海油观澜）** 已投入运行，为广东外海 136 公里、水深 136 米的**陆丰油田**供电。

| 项目 | 参数 |
|---|---|
| 机型 | **MySE 16-260** |
| 整体高度 | >307 m |
| 轮毂高度 | 155 m |
| 风轮直径 | 260 m（扫风面积 53,000 m²） |
| 浮体形式 | **张力腿平台（TLP）** |
| 水深 / 离岸 | 136 m / 136 km |
| 年发电量 | 54 GWh（替代燃油约 15,000 m³，减碳约 3.5 万吨） |
| 抗台设计 | 按 **50 年一遇极端台风**工况设计 |

**关键工艺：整机在码头一次性总装到 TLP 浮体上，整体拖航出海**，明阳称此举显著压缩了深远海恶劣海况下的安装时间与风险。

明阳同时宣称：塔筒极限载荷降低 >15%、年发电量提升 >2%、可利用率提高 10%、运维成本降低最多 15%；并称其在运抗台风机组已超 3,000 台。

## 对我方的含义

**这不是一笔订单，但比大多数订单更值得警惕 —— 它同时封住了三个我方本可以用的差异化说辞。**

1. **「中国厂商没有漂浮式商业化实绩」这条说辞已经作废。** 明阳此前的实绩是半潜式（OceanX 16.6MW 双机），现在再加 TLP 一种浮体形式。**TLP 是欧洲漂浮式管道中被认为最难工程化的一类**（张力腿对水深、系泊预张力、安装精度要求极高）。明阳先于任何欧洲整机厂完成 16MW 级 TLP 商业运行，等于在英国、意大利、法国的漂浮式招标里拿到了一张我方没有的入场资质
2. **直接冲击我方在库的漂浮式标的。** [[英国-Cierco-Llyr漂浮式2x100MW]]（单机 12.5–16.7MW，两场分别验证两种浮体技术）、[[意大利-GreenIT-CIP-三个漂浮式项目]]、[[意大利-Renexia-Sicilian Strait]]、[[英国-Seatrium-TwinHub漂浮式32MW]] —— 这几个项目的技术预选，业主问的第一个问题都会是「你有多少台漂浮式机组在运行、在什么水深」。明阳现在能回答，我方在 [[P1-英国Llyr漂浮式示范整机窗口]] 中悬而未决的「我方有无 15MW 级漂浮式适配机型」这个内部问题，还没有答案
3. **「为海上油气平台供电」这个场景被明阳先做成了商业案例。** 本库已有 [[漂浮式风机为海上油气平台供电]] 一条技术方案记录（对应英国 Culzean 项目）。**同一场景，明阳给出的是 16MW + TLP + 136m 水深，欧洲给出的是单台小机型示范。** 这个差距在向东南亚、中东的国家石油公司推介时会被直接引用
4. **抗台风背书对我方共同市场是负面消息。** 越南、菲律宾、台湾、日本这些台风区市场，明阳的「3,000 台抗台机组 + 50 年一遇设计」是现成的说服材料，而这几个市场恰是我方在库标的最密集的区域

## 建议动作

- **本周内**：由技术口给出书面结论 —— 我方 15MW 级漂浮式机型的成熟度（是否有通过浮体—塔筒耦合载荷校核的版本、有无样机计划）。这个答案同时决定 [[P1-英国Llyr漂浮式示范整机窗口]] 与 [[P1-意大利漂浮式管道提前布局]] 两条战略判断的存废
- 收集 MySE 16-260 的公开技术参数与 TLP 浮体供应商信息，判断其 TLP 方案是自研还是与船厂/油气工程方联合开发 —— 若是后者，我方存在走同一条合作路径的可能
