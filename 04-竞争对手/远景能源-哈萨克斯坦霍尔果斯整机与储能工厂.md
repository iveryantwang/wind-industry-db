## 事件

**远景能源与哈萨克斯坦 Kazakhstan Utility Systems LLP（KUS，Ordabasy 集团旗下）合资，在「霍尔果斯—东大门」自由经济区（七河州 Zhetisu）建设整机与储能系统工厂。**

| 项 | 内容 |
|---|---|
| 合资方 | 远景能源 × **KUS（Ordabasy 集团）** —— KUS 为哈国按装机容量计前四大能源企业 |
| 选址 | **「霍尔果斯—东大门」FEZ，七河州** |
| 奠基 | **2025-01-17**（放置纪念胶囊仪式） |
| 投资额 | **4,000 万美元**，创造 300+ 就业 |
| 整机产能 | **2GW/年 = 250 台** |
| 储能产能 | **1GWh/年 = 100 套** |
| **投产时点** | **2026 年第三季度** |
| 销售结构 | **内销 60% / 出口 40%**（出口目的地：中亚与高加索） |
| 本地含量 | 起步 **30%**，分期提至 **90%** |
| 配套 | 设服务与技术支持中心；与本地高校合作，针对哈国工况做产品优化研究 |

KUS 监事会主席 Dinmukhamet Idrisov 的表述把这个项目的定位说得很直白：不止是造风机和储能，是**引入技术、降低进口依赖、保障能源安全、创造就业并打开出口**。远景高级副总裁 Kane Xu 的表述对应的是另一侧：帮助哈国吸引国际投资、加速能源转型。

## 对我方的含义

**本条补上之后，哈萨克斯坦本地整机产能的格局是完整的 —— 而且两个位置都已经被中国同行占了。**

| | 三一重能 | 远景能源 |
|---|---|---|
| 合资对象 | **Samruk-Kazyna**（主权基金，最大业主兼政策影响方） | **Ordabasy / KUS**（最大民营能源集团之一） |
| 工厂 | Shu，**2GW/年**，2025-09 技术投产 | **霍尔果斯 FEZ，2GW/年整机 + 1GWh/年储能**，**2026 Q3 投产** |
| 覆盖业主侧 | **国有体系** | **民营体系 + 中亚/高加索出口** |

**合计 4GW/年本地整机产能，覆盖国有与民营两条业主线。**

三点判断：

**一、本库既有的「绕开 Samruk 体系找独立 IPP」路径被削弱了。** [[P0-哈萨克斯坦本地产能门槛应对]] 原 action 是「锁定 Samruk 体系外的开发商作为唯一可行入口」——**Samruk 体系外最大的一块现在也有了自己的整机合资厂。**

**二、40% 出口配额指向的是乌兹别克斯坦、高加索与中亚其余市场。** 这不是一个哈国本地化问题，是一个**区域性问题** —— 远景用一个哈国工厂同时拿到了哈国的本地含量加分和周边市场的成本优势。本库 [[明阳智能-格鲁吉亚187MW订单]] 已记录中资同行沿高加索东进，本条是其产能侧的基础设施。

**三、本地含量从 30% 提至 90% 的分期承诺，是未来哈国拍卖引入本地含量条款时的现成标尺。** 一旦规则按已有产能的实际水平设定门槛，无本地产能者被结构性排除 —— 这正是 [[P0-哈萨克斯坦本地产能门槛应对]] 建档时担心的情形，现在多了一个执行主体。

**给商务口的一句话：哈萨克斯坦现在的问题不是订单，是入场券 —— 而两个最好的合资对象（主权基金与最大民营集团）都已名花有主。**
