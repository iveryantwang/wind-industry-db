# 三一重能：埃及苏伊士湾 2GW 风电 + 年产 2GW 整机工厂打包

**发布日 2026-07-01（Windtech International）。本条为 2026-09-07 全量核对时补录，属对本库埃及判断的状态更新。**

埃及计划建设**本国首座风电整机制造厂**，与**苏伊士湾 2,000MW 风电项目**打包推进。合作方为**整机厂三一重能（Sany）、埃及输电公司（EETC）与新能源与可再生能源署（NREA）**。

| 项 | 内容 |
|---|---|
| 工厂年产能 | **至多 2GW/年整机** |
| 工厂建设周期 | 最终协议签署后**两年内**建成 |
| 配套项目 | 苏伊士湾 **2,000MW** 陆上风电 |
| 项目并网 | **23 个月内**接入国家电网 |
| 埃方主体 | EETC（输电公司）＋ NREA（可再生能源署）—— **均为国家机构** |

## 对我方的含义 —— 这条直接动摇本库的埃及 P0

**本库 [[P0-埃及RasShokeir1GW整机窗口]] 的判断依据写的是：「我方在埃及既无渠道也无业绩，而 Vestas / SGRE / Nordex / GE Vernova 在苏伊士湾均有存量业绩。」**

**这个竞争格局描述是不完整的 —— 它漏掉了中国厂商，而中国厂商在埃及的位置比四家国际厂商更靠前。**

把本条与其他已知事实并排：

| 厂商 | 在埃及的位置 |
|---|---|
| **三一重能** | **2GW 项目 + 年产 2GW 工厂，对手方是 EETC 与 NREA 两个国家机构** |
| **远景能源** | Amunet I 500MW 已投运（非洲最大风电场）＋ Amunet II 500MW 已签，与 AMEA Power 合计 **1GW**（见 [[远景能源-埃及AmunetII500MW与埃及1GW组合]]） |
| 金风科技 | 已完成红海 500MW 风电场 |
| Vestas / SGRE / Nordex / GE Vernova | 苏伊士湾存量业绩 |

**结论：埃及不是一个「我方与四家国际厂商竞争」的市场，而是一个中国同行已经先行数年、并且正在把先行优势制度化（本地工厂）的市场。**

### 为什么「工厂」这一层比「订单」更要命

三一这一步不是拿一个 2GW 订单，是**把自己变成埃及的本土产能**。一旦年产 2GW 的工厂落地：

1. **埃及后续项目的本地含量要求会自然向该工厂倾斜** —— 这不需要政策歧视，只需要「优先采购本地制造」这一条通行规则
2. **对手方是 EETC 与 NREA 两个国家机构**，意味着这不是一笔商业交易，是一个产业政策安排
3. **工厂建成需两年**（协议签署后），即约 2028 年 —— **Ras Shokeir 1GW 的整机定标窗口（PPA 后 6–12 个月，即 2027 年上半年前）恰好落在工厂建成之前**

**第 3 点是唯一的好消息：Ras Shokeir 的定标很可能早于三一工厂投产，因此本地含量尚未成为硬门槛。但这个时间差只有一次，且正在收窄。**

## 与本库既有判断的关系

这条同时是 [[产能出海的市场准入前置条件]] 的一个**反向样本**：

- 该条记录的是英国——明阳「用产能换准入」失败，结论是「准入确定性 → 订单可见度 → 产能投资」
- **埃及是相反的情形：产能投资本身就是准入，因为埃及没有安全审查、且主动希望引入本土制造**

**同一套打法在两类市场结果完全相反。判别式是：该国把外资产能视为安全风险，还是视为产业成果。** 已在 [[产能出海的市场准入前置条件]] 补记。
