# 远景能源：埃及 Amunet II 500MW 签约，与 AMEA Power 在埃及合计 1GW

**发布日 2026-06-18（非洲能源论坛 AEF 2026 期间签署）。本条为 2026-09-07 全量核对时补录，属对本库埃及判断的状态更新。**

| 项 | 内容 |
|---|---|
| 项目 | **Amunet II，500MW**，埃及 |
| 业主 | **AMEA Power**（总部迪拜） |
| 整机 | **远景能源** |
| 签署场合 | 非洲能源论坛（AEF）2026，2026-06 |
| 前序项目 | **Amunet I 500MW**，Ras Ghareb，**2025 年投运，为非洲最大风电场** |
| 合计 | 两期共 **1GW**，为 AMEA Power 在埃及的风电组合 |

这是远景与 AMEA Power 在埃及的**第二次合作**。

## 对我方的含义

**远景在埃及不是新进入者，是已投运非洲最大风电场、并已拿到第二期的存量供应商。**

对 [[P0-埃及RasShokeir1GW整机窗口]] 的意义有两层：

**第一层是竞争位次。** 本库该 P0 建档时把埃及的竞争格局描述为「Vestas / SGRE / Nordex / GE Vernova 在苏伊士湾均有存量业绩」。加上远景 1GW、金风红海 500MW、三一 2GW 项目 + 工厂（见 [[三一重能-埃及2GW项目与年产2GW整机工厂]]），**真实格局是中国厂商已在埃及占据主导，而我方是这个市场里唯一没有业绩的中国整机厂之一。**

**第二层更实际：业主重复采购的惯性。** Amunet I → Amunet II 是同一业主、同一整机商的连续两期。埃及项目的整机选择呈现明显的**业主级锁定**特征：

| 业主 | 整机 | 状态 |
|---|---|---|
| AMEA Power | 远景能源 | Amunet I 已投运 → Amunet II 已签 |
| （红海项目业主） | 金风科技 | 500MW 已完成 |
| EETC / NREA | 三一重能 | 2GW 项目 + 工厂在谈 |
| **Infinity Power ＋ Hassan Allam** | **未定** | **Ras Shokeir 1GW —— 本库标的** |

**Ras Shokeir 的业主组合是上表里唯一还没有被锁定的一家。** 这既是机会（还没定），也是提示（其他业主都已经有各自的既定供应商，我方要么拿下 Infinity Power，要么在埃及就没有位置了）。

**同时须核实：Infinity Power 的大股东之一是 Masdar（阿布扎比），而 AMEA Power 同为海湾资本背景。海湾开发商在埃及的整机选择是否已形成共同偏好，是本条最该追的问题。**

## 待办

- [ ] 核实 Amunet I 与 II 用的具体机型与单机容量 —— 埃及陆上的主流规格是本库空白
- [ ] 核实 Infinity Power（Masdar 参股）与 AMEA Power 在整机供应商选择上是否有交叉决策人或共同顾问
- [ ] 查远景在埃及是否有本地服务基地或产能计划 —— 若有，埃及的中国厂商本地化就不止三一一家
