## 项目简介

这是哈萨克斯坦 2026 年可再生能源拍卖中**风电部分容量最大的单一标段**（450MW 中的 250MW），本库自 2026-07-29 起在 [[P0-哈萨克斯坦450MW拍卖中标方补查]] 中持续追查其中标方，**至 2026-08-24 首次查实**。

| 项 | 内容 |
|---|---|
| 拍卖日期 | **2026-04-27**（阿斯塔纳时间 15:00 开始） |
| 拍卖组织方 | KOREM（哈萨克斯坦电力与容量市场运营商） |
| 分区 | **西部区（阿特劳州 / Атырауская область）** |
| 装机容量 | **250 MW** |
| 中标方 | **ТОО «Батыс Каспий Энерго»** |
| **中标电价** | **22.32 坚戈/kWh（不含增值税）** |
| 上限电价 | 22.68 坚戈/kWh |
| 降价幅度 | 仅 **约 1.6%** |
| 入围企业数 | **2 家** |
| 报价轮次 | 16 次价格提交 |

| 投运期 | 签约后 **36 个月** |
| 购电合约期 | **20 年** |

## 整机采购状态

**整机未定，且截至 2026-08-24 未见任何整机厂与本项目的公开关联。**

窗口判断：**已经开着，且正在快速收窄。**

- 中标日 2026-04-27 + 36 个月投运期 → **投运死线约 2029 年 4–5 月**
- 250MW 级陆上项目从整机定标到投运，正常需要 24–30 个月（设计、制造、运输、吊装、调试）
- 倒推：**整机必须在 2026 年 Q4 至 2027 年 Q1 之间定标**，否则工期不保
- 也就是说，**报价窗口大约还有 3–6 个月**，是本库哈国条目中窗口最紧的一个

**已经过去 4 个月而我方零接触** —— 中标至今 119 天，这段时间业主大概率已在做整机询价。本条建立时窗口就已经消耗过半。

## 中标价对整机报价空间的约束

**22.32 坚戈/kWh ≈ USD 42–44/MWh**（按 2026 年汇率区间估算），是本库记录的哈国拍卖中已知的**实际中标价**，此前只有上限价 22.68 可用。

关键在于**降价幅度只有约 1.6%**：

- 对比同期哈国光伏拍卖动辄 30–50% 的降幅（见 [[哈萨克斯坦-2026可再生能源拍卖时间表]]），风电这一场几乎没有价格竞争
- 直接原因是**只有 2 家入围** —— 参与度低，中标方无需压价
- **这对整机厂是好消息**：业主拿到的是接近上限的电价，度电收入空间比预期宽，对整机价格的挤压相应小于按上限价倒推的悲观测算
- 本库 [[哈萨克斯坦阿克托别100MW拍卖电价与2028投运约束]] 中「22.68 上限价反推的整机可接受价格区间偏紧」的结论**应据此放宽**：实际成交价与上限价几乎持平，不是打到底价成交

**同时也说明哈国风电拍卖池竞争不足** —— 250MW 标段只有 2 家投标，与 [[P0-哈萨克斯坦本地产能门槛应对]] 中「大项目走政府间协议直签、拍卖池被边缘化」的判断一致。愿意进拍卖池的开发商本来就少，这既降低了标的质量，也意味着**中标方很可能是本地中小型开发商，而非有既定整机供应关系的国际大玩家 —— 这对我方反而是机会**。

## 业主背景（信息缺口，须优先补齐）

**ТОО «Батыс Каспий Энерго»（意为「西里海能源」）的股东结构、既往风电业绩、是否与中资或 Samruk 体系关联，目前一概不明。** 这是本条最大的不确定性：

- 若为独立本地开发商 → 整机开放竞争，机会实在
- 若为中资背景合资公司 → 大概率整机已内定（参照 [[三一重能-哈萨克斯坦Mirny与Shu本地产能]]、[[远景能源-哈萨克斯坦Mirny 1GW整机供货]] 的路径）
- 若挂靠 Samruk-Kazyna 体系 → 按 [[P0-哈萨克斯坦本地产能门槛应对]] 的结论，通道实质封闭

**在查清股东结构之前，不应投入技术方案资源。** 这是 [[P0-哈萨克斯坦Masdar 1GW紧急核实]] 教训的直接应用。
