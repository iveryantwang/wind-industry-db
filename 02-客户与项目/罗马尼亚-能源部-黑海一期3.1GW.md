## 项目简介

罗马尼亚能源部划定的黑海六片海上风电海域（合计约 11.5GW）中的**第一期**，也是唯一进入短期招标计划的一批：

| 场址 | 容量 | 备注 |
|---|---|---|
| 一期场址 A | 1.9GW | 单体规模最大 |
| 一期场址 B | 600MW | |
| 一期场址 C | 600MW | |

二期为 1.8GW + 800MW，三期为 6GW（固定式+漂浮式混合），本笔记只覆盖一期。

法律基础为 Law No.121/2024。名录与批准决定于 2026-07-28 进入公众咨询，支撑文件 2026-07-22 发布。

## 整机采购状态

**整机未定，开发商也未定。** 目前连特许权都尚未授予 —— 顺序是：名录批准 → 特许竞争程序 → 开发商取得场址 → 环评与许可 → 整机采购。

**机会等级判定为「中」而非「高」**：容量远超 100MW，整机确实未定，但阶段仍在「前期」（名录公众咨询），距整机定标至少 2–4 年，不符合「核准/招标中/已中标/环评后期」的高机会口径。

黑海一期水深与地质条件适配固定式，与我方现有固定式平台匹配度较高；三期 6GW 明确含漂浮式。

## 2026-08-21 更新：能源部正式提出三片特许海域

罗马尼亚能源部已向外提出黑海罗马尼亚海域的**三片特许区域**，合计 3.1GW —— 一期由 1 片 1.9GW + 2 片各 600MW 构成，与本笔记 2026-07-29 记录的口径一致，此次为部级正式提案层面的确认（据 Mediafax 报道，reNEWS 转述）。

新增信息：

- 三片特许海域**均适用固定式基础**，以现有海上技术即可实施，且已避开高敏感区域
- 罗马尼亚《2025–2035 能源战略》目标为 2035 年装机 3GW 海上风电，与本期 3.1GW 规模对应
- 世界银行《罗马尼亚海上风电路线图》测算黑海技术可开发潜力约 76GW（平均风速 >7.5m/s），其中约 22GW 适用固定式、54GW 需漂浮式；3GW/2035 为「中性情景」，「加速情景」为 7GW

**对整机窗口的影响：无实质变化。** 仍处于特许授予前，开发商与整机均未定，机会等级维持「中」。但「三片全部为固定式」这一条对我方是正面信号 —— 与我方现有固定式平台匹配，且不必等待 15MW 级漂浮式版本的内部定性结论。
