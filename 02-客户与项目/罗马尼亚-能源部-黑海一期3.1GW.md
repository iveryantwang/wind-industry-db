## 项目简介

罗马尼亚能源部划定的黑海六片海上风电海域（合计约 11.5GW）中的**第一期**，也是唯一进入短期招标计划的一批：

| 场址 | 容量 | 备注 |
|---|---|---|
| 一期场址 A | 1.9GW | 单体规模最大 |
| 一期场址 B | 600MW | |
| 一期场址 C | 600MW | |

二期为 1.8GW + 800MW，三期为 6GW（固定式+漂浮式混合），本笔记只覆盖一期。

法律基础为 Law No.121/2024。名录与批准决定于 2026-07-28 进入公众咨询，支撑文件 2026-07-22 发布。

## 整机采购状态

**整机未定，开发商也未定。** 目前连特许权都尚未授予 —— 顺序是：名录批准 → 特许竞争程序 → 开发商取得场址 → 环评与许可 → 整机采购。

**机会等级判定为「中」而非「高」**：容量远超 100MW，整机确实未定，但阶段仍在「前期」（名录公众咨询），距整机定标至少 2–4 年，不符合「核准/招标中/已中标/环评后期」的高机会口径。

黑海一期水深与地质条件适配固定式，与我方现有固定式平台匹配度较高；三期 6GW 明确含漂浮式。
