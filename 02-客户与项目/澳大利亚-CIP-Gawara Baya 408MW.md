## 项目简介

**Gawara Baya**（原名 Upper Burdekin Wind Farm）位于北昆士兰 Ingham 西南约 65km 的 Gugu Badhun 原住民传统领地。

| 项 | 值 |
|---|---|
| 风电装机 | **408MW** |
| 储能 | **104MW 构网型（grid-forming）BESS** |
| 风机台数 | **68 台**（推算单机约 6MW） |
| 融资 | **17 亿澳元，10 家银行银团** |
| 投运 | **2030 年全容量** |
| 卖方 | Windlab（澳洲本土开发商） |
| 买方 | CIP / Copenhagen Infrastructure V 旗舰基金（100%） |
| 售电安排 | 与 Stanwell、SmartestEnergy 的长期购电协议 + 参与澳联邦 Capacity Investment Scheme（CIS） |
| 区域经济 | 逾 2 亿澳元本地投入，500 个直接与间接岗位 |

来源对台数口径存在小分歧：reNEWS 稿件与 CIP 通稿记 **68 台**，Infrastructure Pipeline 项目库记 **69 台**。两个口径并列，不取中值。

## 整机采购状态

**整机商未公开披露，但窗口应视为已关闭。**

判断依据不是公告，而是交易结构：**CI V 已作出 FID 并完成 17 亿澳元融资关闭，且宣布「即刻开工」。** 澳洲项目在这一节点上，整机供货协议（TSA）是融资关闭的前置文件之一 —— 银团不会在整机未定的情况下放款。因此整机大概率已在 Windlab 开发阶段或 CIP 收购谈判中锁定，只是未随本次公告披露。

**唯一的残余可能：** 若 TSA 系「有条件签署」且存在机型替换条款（澳洲项目在 GPS 并网合规环节偶有此情形），2027 年前仍有极小的变更窗口。但这是需要验证的假设，不是可依赖的机会。

因此 `opportunity` 定 **低**，`oem` 留空 —— 留空在此**不代表机会**，而代表**未披露**，这一点须与本库其他留空条目区分。

## 本条的真正价值：不是这个项目，是它暴露的盲区

408MW 是澳洲近年单体规模靠前的陆上项目，从 Windlab 开发到 CIP 收购再到 FID 全过程，**本库此前没有任何一条前期记录**。等到 FID 当日才第一次入库，意味着整机窗口已经在我方视野之外走完了。

同类风险的对照条目：[[澳大利亚-Neoen-Narrogin 179MW]]（远景 2026-07 拿下）、[[澳大利亚-Tilt Renewables-Waddi 108MW]]（Vestas）。**澳洲陆上正在被逐个锁定，而我方的入库时点普遍晚于定标时点。**
