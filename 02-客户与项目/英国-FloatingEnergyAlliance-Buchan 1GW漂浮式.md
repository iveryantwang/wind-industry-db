## 项目简介

**2026-09-07** 的新信息是**浮体侧的产能落地进展**，项目本体状态未变。

| 项 | 内容 |
|---|---|
| 业主 | **Floating Energy Alliance** —— BayWa r.e.（格拉斯哥/爱丁堡）+ Elicio（比利时）+ **BW Ideol（持股 33%）** |
| 容量 | **约 1,000MW** |
| 位置 | 苏格兰 Fraserburgh 东北约 75km，阿伯丁郡外海 |
| 水深 | 至 **110m** |
| 开发权 | 2022-01 经 **ScotWind** 取得（苏格兰皇家资产管理局） |
| 浮体 | **BW Ideol 混凝土 Damping Pool，已确定为首选浮体**，至多 **70 座**，承诺苏格兰本地制造 |
| 核准 | 2025-10 已递交陆上核准申请 |
| Owner's Engineer | Kent（2026-05 任命），推进至 FEED |
| FID / 投运 | **2029 / 2033** |
| **整机** | **未公开** |

**由 1GW ÷ 至多 70 台反推，单机容量在 14MW 级以上** —— 与本库 [[环评阶段的机型容量区间锁定14至22MW]] 记录的漂浮式主流区间一致。

### 2026-09-07 的具体事件

苏格兰政府经 **Highlands and Islands Enterprise（HIE）**、与 Scottish Development International（SDI）配合，向 **BW Ideol 法国实体**拨款 **逾 £778,000**，支持 **18 个月 FEED 研究**，用于其 **Ardersier 港漂浮式基础量产工厂**：

| 项 | 数值 |
|---|---|
| 产出节奏 | 单线 **每 12 天一座浮体** |
| 折算年产能 | 约 **500MW/年** |
| 直接岗位 | 约 **1,200 个**（高地地区） |
| Buchan 项目自身 | 建设期约 **2,900 个**岗位、全生命周期为苏格兰带来 **逾 £20 亿**经济价值 |
| 场地权 | BW Ideol 2021-09 已签协议取得 Ardersier 场地**混凝土浮体独家使用权** |

## 整机采购状态

**整机未定，且窗口很长 —— 但「窗口长」在这个项目上不等于「可以晚动」。**

FID 在 2029 年，整机定标常规在 FID 前 12–18 个月，即 **2027 年底至 2028 年**，表面上还有两年多。但本项目有一个与常规不同的地方：

**浮体已经先于整机锁定，且浮体方是业主的股东（BW Ideol 持股 33%）。**

这意味着整机的接口条件（塔底载荷、重量上限、总装工艺、拖航方案）**会由已经定下来的 Damping Pool 混凝土浮体反向约束整机选型**，而不是相反。我方若在浮体设计冻结（18 个月 FEED，即约 **2028 年 3 月前**）之后才接触，能改的只剩商务条件，改不了技术适配性。

**真正的窗口不是 2028 年的整机招标，是这 18 个月的 FEED —— 约到 2028-03。**
