## 项目简介

**2026-08-27**，乌克兰农业综合企业 **Kernel** 与**丹麦出口与投资基金（EIFO，Eksport- og Investeringsfonden）**签署贷款协议，为其**首个风电项目**融资。

| 项 | 内容 |
|---|---|
| 业主 | Kernel Holding S.A. |
| 位置 | 乌克兰中部 |
| 容量 | **94.5MW** |
| 台数 | **21 台** |
| **整机** | **Vestas（供货 + 安装）** |
| 单机推算 | 94.5 ÷ 21 = **4.5MW** |
| 储能 | 配套工业级 BESS，用于峰时出力平衡 |
| 融资 | **EIFO 贷款 1 亿欧元**，在其对乌投资支持专项下提供 |

**EIFO 是丹麦国家出口与投资机构，其定位是「为涉及丹麦企业的国际项目提供融资」。**

## 整机采购状态

**整机已定标 Vestas，本项目对我方已关闭。** `opportunity` 按字段规范记为 `已失单`。

**但须诚实标注：这不是一次「输掉的竞标」，我方从未进入该项目。** 本库此前对乌克兰的记录仅有 [[乌克兰-2026绿色拍卖风电配额250MW]] 一条政策笔记，没有任何项目级跟踪。**记为「已失单」是字段口径的机械结果；真实性质是「结构性缺席」——我方连投标的资格链条都不在其中。** 原因见下。

## 为什么我方进不去：融资绑定采购

**这条的价值不在 94.5MW，而在它暴露的准入机制。**

EIFO 的机构定位是**为涉及丹麦企业的国际项目提供融资**。也就是说：

```
丹麦国家出口信贷 1 亿欧元  →  条件是项目采用丹麦供应链  →  整机自然是 Vestas
```

**整机不是在一场比价中选出来的，是随融资一起进来的。** 在这种结构下，报价、机型性能、交付期都不是决定变量 —— **谁能带来项目融资，谁就带来整机订单。**

**这在高风险市场里是常态而非例外。** 战时乌克兰的商业银行融资几乎不可得，项目能否落地完全取决于能否拿到 ECA（出口信用机构）或 DFI（开发性金融机构）的钱。而每一家 ECA 的钱都绑着自己国家的供应链：

| 资金来源 | 绑定的供应链 |
|---|---|
| EIFO（丹麦） | Vestas |
| EKF / SACE / Euler Hermes 等欧洲 ECA | 欧系整机与部件 |
| EBRD / EIB | 通常不绑国别，但有采购规则与合规门槛 |
| 中国进出口银行 / 中信保 | 中国整机与 EPC |

**本库已有的同类样本可以对照：** [[哈萨克斯坦Mirny 1GW EBRD 5.48亿美元AB贷款结构]]（EBRD 牵头、多国联贷，整机为远景 + 三一）、[[哈萨克斯坦Jambyl 1GW的AIIB融资与美元计价PPA结构]]、[[阿曼JBB 120MW项目融资关闭与20年PPA结构]]。**把这几条并排看，一个模式很清楚：在新兴与高风险市场，整机归属高度相关于资金归属，而非报价高低。**

## 对我方的三条含义

**① 乌克兰战后重建市场的准入路径是金融路径，不是商务路径。** 现在开始跑乌克兰的开发商与 EPC，收益有限；应该跑的是**能为乌克兰项目提供融资的机构**，以及**中方 ECA 对乌业务的开放状态**。

**② 本库应把「资金来源」作为项目建档的常规字段来对待。** 目前 `02-客户与项目` 的 YAML 里有 `capex`，但没有「资金来源 / 是否 ECA 绑定」。**知道一个项目的钱从哪来，往往比知道它的容量更能预测整机归属。** 建议在正文固定记录，与 [[环评阶段的机型容量区间锁定14至22MW]] 提出的「环评容量区间」并列，作为两条前置判据。

**③ 4.5MW × 21 台 + BESS 的配置，是东欧陆上风储项目的典型规格。** 这个尺寸段与 [[风储一体化项目的整机与储能打包供货]] 记录的打包供货模式一致 —— 我方若要在同类市场竞争，风机与储能的打包能力是必要条件，单卖风机会被结构性排除。
