## 项目简介

| 项 | 内容 |
|---|---|
| 装机容量 | **约 1,000MW**（2025-06 口径） |
| 场址 | 摩洛哥**大西洋沿岸索维拉（Essaouira）附近** |
| 背书机构 | **MASEN**（摩洛哥可持续能源署） |
| 可研委托方 | **EIB**，资金来自 **FEMIP 信托基金** |
| 可研承接方 | **OWC 牵头联合体**（PHENIXA、Gaïa Terre Bleue、NOVEC、SOFECO；ABL 海事） |
| 可研周期 | **两年**（2026-09 起算） |
| 目标开工 | **2029 年** |
| **整机供应商** | **未公开，尚无招标** |

**国家层面资源背景（世界银行集团估算）：** 摩洛哥海上风电技术潜力约 **200GW**，其中 **固定式约 22GW、漂浮式约 178GW**。

**沿革：**

| 时间 | 事件 |
|---|---|
| 2022-09 | EIB 与 MASEN 签署合作协议，200 万欧元赠款用于可研 |
| 2024 | EIB 启动两年期技术援助招标；同年 7 月取消后重新招标 |
| 2025-06 | 项目推进为索维拉附近约 1GW，目标 2029 开工（据地中海联盟；列入蓝色地中海伙伴关系支持名单） |
| **2026-09-03** | **EIB 委任 OWC 牵头联合体，可研正式启动** |

## 整机采购状态

**整机未定，且距离招标还很远 —— 但这不是「太早不用管」，而是「唯一能改规则的时候」。**

**时间轴推算：** 两年可研（至 2028-09）→ 开发决策与招标 → 2029 开工。**整机定标最早在 2028 年，最晚可能 2028 年底。**

**判定为 `opportunity: 中`：** 整机未定、容量 1,000MW 远超门槛，但阶段在「前期 / 可研」，未达核准或环评后期，按字段规范口径为 `中`。

**但本条的真实价值不在等级，在可研范围清单本身：**

| 可研条目 | 对整机厂的实际含义 |
|---|---|
| **风电场概念设计** | 决定单机容量假设、机位布置、水深与基础型式区间 |
| **港口与物流** | 索维拉及周边港口的吊装/出运能力，直接卡死可用机型上限 |
| **监管框架** | 本地含量要求、认证体系、并网技术规范的成文依据 |
| **电网影响与接入** | 并网点容量与技术规范（低电压穿越、频率响应等） |
| 市场与供应链 | 本地配套可达性，影响是否要求本地化产能 |

**这五条里有四条直接决定「我方能不能投、能投什么」。** 摩洛哥目前没有一台海上风机，这些规则全部是空白 —— **空白意味着谁在这两年提供输入，规则就更像谁的产品。**

**对中国整机厂的特殊性：** 这是一个由 **EIB 出资、欧洲咨询公司主导**的可研。认证体系、供应链评估与本地含量条款的默认参照系会是欧洲的。**若我方不在此期间提供输入，两年后拿到的招标文件很可能天然不利于中国厂商** —— 这不是歧视，是路径依赖：可研写什么，招标就抄什么。
