## 项目简介

**Forsinain Forest 风电场**，开发商 **Low Carbon**（英国独立可再生能源开发商，自持与开发并行）。

| 项 | 内容 |
|---|---|
| 位置 | 苏格兰高地，Forsinard 以北 3km、Melvich 以南 16km |
| 台数 | 最多 **12 台** |
| 装机 | 最高 **86MW** |
| 推算单机 | **约 7.2MW**（86 ÷ 12） |
| 年发电 | 约 **318,000MWh**（对应等效满发约 3,700 小时，高地风资源口径） |
| 减排 | 年避免逾 135,000 吨 CO₂ |
| 配套 | 新建与升级道路、升压站、场内施工设施 |
| 生态 | 场址内实施林地转泥炭沼泽（forest-to-bog）修复 |
| 社区回馈 | **5,000 英镑/MW**，约 43.2 万英镑/年 |
| 地方税 | 约 100 万英镑/年（高地议会） |

**环境定位是本项目的关键设计：** 场址选在非本土商业林地内、完全避开 Flow Country UNESCO 世界遗产地，并主动做泥炭沼泽修复 —— 这是针对苏格兰高地泥炭地开发争议的正面回应，也是 Section 36 能否过关的核心。

## 审批阶段

- **2026-08-28**：向苏格兰政府能源许可署（Energy Consents Unit, ECU）递交 **Section 36** 申请
- 英国规则：苏格兰境内 **≥50MW** 的陆上风电项目须走 Section 36 而非地方规划许可
- 苏格兰 Section 36 的实际审批周期通常 **2 年以上**，若高地议会提出异议还可能触发公开听证（Public Local Inquiry）

## 整机采购状态

**整机未定，且窗口尚未开启。**

- 苏格兰陆上项目的整机询价通常在 **Section 36 获批之后**启动，本项目 2026-08 才递交申请，按常规节奏整机定标最早在 **2028 年**
- 但机型区间会在申请阶段被环评文本锁定：**叶尖高度、转子直径、噪声与阴影影响的建模参数已写入申请材料**，后续换机型若超出建模包络需重新评估。这与我方在 [[环评阶段的机型容量区间锁定14至22MW]] 中记录的机理一致（该条为海上口径，陆上同理）
- 单机 7.2MW 档位对应 Vestas V172-7.2、Nordex N163/6.X 等在英已有装机记录的机型；**我方若无英国已运行机组的业绩背书，在此档位竞争力有限**

**机会等级判定为「中」：** 整机确实未定，但①容量 86MW < 100MW 门槛；②阶段为「前期/申请中」，不属于核准/招标中/已中标/环评后期。两条都不满足「高」的口径。
