## 项目简介

2026-08-19，Ørsted 在台湾提出的 **Dadu II（大肚二期）**进入环境影响评估程序。

| 项 | 内容 |
|---|---|
| 位置 | 彰化县外海，离岸最近点 **约 38 公里** |
| 海域面积 | **约 234.6 平方公里** |
| 总装机上限 | **不超过 2,002MW** |
| **单机容量区间** | **14MW – 22MW** |
| 台数与布置 | **尚未确定** |
| 环评阶段 | 公众参与中；**2026-08-13 已在彰化县召开公众说明会** |

## 🎯 最有价值的一条信息：机型区间被写进环评文件

**「14MW–22MW」不是媒体口径，是环评申请文件里的参数。** 这意味着三件事：

1. **我方 15MW 级机型落在区间内，形式上不被排除。** 环评文件中的容量区间一旦核定，后续机型选择须落在区间内，超出区间需重新报批。**这是一道在项目最早期就被划下的准入线，而它现在对我方是开着的。**
2. **上限 22MW 说明 Ørsted 为下一代机型预留了空间。** 目前全球商用最大机型在 18–20MW 级（明阳、金风、Vestas V236 为 15MW 级）。**22MW 上限指向 2030 年后的投运时点，也说明 Ørsted 不打算沿用 Greater Changhua 的 SG 14-236。**
3. **台数未定 = 单机容量未定 = 供应商未定。** 若已锁定供应商，台数与布置通常同步确定。**台数留白是本条最实在的机会信号。**

## 整机采购状态

**整机未定，但阶段过早 —— `opportunity` 判为「中」而非「高」。**

按 [[字段规范]] 口径：整机确未定、容量 2,002MW ≥100MW，但**阶段为环评公众参与中期**，不满足「核准 / 招标中 / 已中标 / 环评后期」。同批的 [[台湾-Orsted-Dadu I 924MW]]（EIS 已完成）才是近期可动的那一个。

**窗口估算：** 环评公众参与 → 环评通过通常需 12–24 个月；整机询价最可能落在 **2028–2029 年**。但**技术介入窗口是现在** —— 机型区间与布置方案在环评阶段成型，等到询价时参数早已锁死。
