## 项目简介

**東京電力リニューアブルパワー（TEPCO RP）** 于 **2026-08-20** 递交規劃階段環境考量文件（配慮書），正式启动千叶县**銚子（Choshi）沖**最高 **420MW** 固定式海上风电项目的环评程序。千叶县自 **2026-08-21** 起公开征询意见，**2026-09-25** 结束。

| 项 | 内容 |
|---|---|
| 业主 | TEPCO Renewable Power |
| 海域 | 千叶县銚子沖（环评范围含旭市一部分） |
| 用海面积 | 约 **4,000 公顷** |
| 基础形式 | **固定式** |
| **单机容量区间** | **15–20MW** |
| 台数上限 | **27 台** |
| 总容量上限 | **420MW** |
| 开工 | 2031 年以后 |
| 投运 | 2032 年以后 |
| 整机 | **未定标** |

## 场址的来历：这是一块「回收再释出」的地

銚子沖是日本**首轮固定式海上风电招标（Round 1）**的场址之一。

| 时间 | 事件 |
|---|---|
| 2021-05 | Ørsted + TEPCO 联合体投标銚子沖 370MW |
| 2021-12 | **三菱商事牵头的联合体中标**，銚子 390.6MW，机型为 GE；同轮另中标秋田县两个场址 |
| 2025-08 | **三菱以「宏观经济环境发生实质性变化」为由，宣布退出全部三个场址** |
| 其后 | 日本政府启动 Round 1 三场址（銚子、能代・三种・男鹿、由利本荘）**重新招标** |
| **2026-08-20** | **TEPCO RP 单独启动銚子新项目环评（420MW）** |

**TEPCO 是 2021 年那轮的落标方，如今以自有项目形式重回同一片海域，且容量从 390.6MW 提到 420MW。**

## 整机采购状态

**整机未定标，且窗口很长 —— 但机型准入线已经在划了。**

**环评文件已写死单机容量区间 15–20MW、台数上限 27 台。** 按本库 [[环评阶段的机型容量区间锁定14至22MW]] 已确立的判据：**容量区间一经主管机关核定，后续机型须落在区间内，超出需重新报批。也就是说，一款机型能否进入本项目，在 2026-08-20 递交配慮書那一刻就已经决定了一半。**

**区间宽度解读（按既有判据）：**

- 15–20MW 是 **5MW 宽**，比 Ørsted Dadu II 的 14–22MW（8MW 宽）窄，但仍跨越当前 15MW 级与下一代 18–20MW 级两个代际
- **不构成「已隐含锁定」**：若 TEPCO 已倾向某家 15MW 级机型，没有必要把上限开到 20MW
- 但**下限 15MW 排除了 14MW 级机组** —— 这一点值得注意：Siemens Gamesa 的 SG 14-236 与同级产品在本项目**不满足区间下限**

**COD 2032 年以后，整机询价窗口推定在 2029–2030 年**，距今 3–4 年。`opportunity` 因此定为**中**（容量与业主都够，但阶段过早），而非高。

**但「窗口远」不等于「现在不用做事」** —— 本项目当前正处在**环评公众咨询期（至 2026-09-25）**，这恰恰是技术输入唯一能影响容量区间与布置方案的时点。窗口一旦过去，参数就固化了。

## 对我方的含义

**一、日本市场正在从「大商社主导」转向「电力公司自持」。** 三菱退出后，接手的是 TEPCO 这样的电力公司。**商社的采购逻辑是价格与总包，电力公司的采购逻辑是长期可用率与运维体系** —— 我方在日本的打法应据此调整。

**二、这块地会被招两次。** TEPCO 的自有项目环评与政府对 Round 1 三场址的重新招标同时推进，两条线可能在銚子重叠。**需要判定：TEPCO 这个 420MW 项目是走重新招标通道，还是独立的新场址申请？** 这直接决定接触对象是 TEPCO 还是招标主管部门。见 [[日本-Round1三场址退出后重新招标]]。

**三、15MW 下限对本库机型策略是一条硬信息。** 日本这一批新项目若普遍以 15MW 为区间下限，我方 15MW 级产品处在区间边缘而非中心 —— 边缘位置在评分中通常不利。参见 [[漂浮式15MW机型资格内部定性]]（该条针对漂浮式，本条为固定式，逻辑同源）。
