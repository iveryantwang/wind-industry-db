## 交互式查询（仅本地 Obsidian 可用，需安装 Dataview 插件）

```dataview
TABLE WITHOUT ID
  region AS "区域", country AS "国别", customer AS "客户",
  link(file.link, project) AS "项目", opportunity AS "机会",
  capacity_mw AS "容量MW", unit_mw AS "单机MW", turbine_count AS "台数",
  segment AS "类型", status AS "状态", oem AS "整机商", cod_year AS "并网年"
FROM "02-客户与项目"
WHERE type = "project"
SORT opportunity ASC, capacity_mw DESC
```
