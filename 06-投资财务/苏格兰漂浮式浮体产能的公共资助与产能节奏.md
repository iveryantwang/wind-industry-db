# 苏格兰漂浮式浮体产能的公共资助与产能节奏

## 数字

| 项 | 数值 | 备注 |
|---|---|---|
| 公共资助 | **£778,000+** | 仅覆盖 **18 个月 FEED**，非建厂投资 |
| 资助方 | HIE（苏格兰政府） | SDI 负责把项目争取到苏格兰 |
| 受资助方 | BW Ideol（法国实体） | BW Ideol AS 子公司 |
| 单线节奏 | **每 12 天一座浮体** | |
| 年产能 | **约 500MW/年** | 由上一行折算，reNEWS 原文口径 |
| 直接岗位 | 约 **1,200 个** | 工厂投运后 |
| Buchan 项目建设期岗位 | **2,900 个** | 业主口径 |
| Buchan 全生命周期经济价值 | **逾 £20 亿** | 业主口径 |
| 场地权取得 | 2021-09 | 混凝土浮体独家权 |

## 三点可用于我方测算的结论

### 1. 公共资金介入的量级极小，但介入的时点极早

**£778k 在一个 1GW 项目面前几乎可以忽略，真正的信号是介入阶段：FEED，不是建设。** 这与本库 [[法国五港漂浮式配套投资撬动比与整机交付成本影响]]（2.585 亿欧元，五港基建）的模式不同 —— 法国是政府先建基建再招商，苏格兰是**政府用小钱把私营方的技术方案锁在本地**。

对我方的含义：**在英国，本地含量的竞争发生在 FEED 阶段而非投标阶段。** 等到项目招标时再谈本地化承诺，位置已经被占。

### 2. 500MW/年是一个可以倒推交付节奏的硬约束

Buchan 约 1GW ÷ 500MW/年 = **浮体供应至少需要 2 年**。若整机与浮体同步交付，我方的产能占位要求就是**连续 2 年、每年 500MW 级的 14MW+ 海上机组交付能力**，且要匹配 Ardersier 港的总装吞吐（见 [[漂浮式整机码头总装的港口吞吐约束]]）。

这是本库首次拿到一个**具体的漂浮式浮体产线节奏数字（12 天/座）**，此前 [[漂浮式整机码头总装的港口吞吐约束]] 只有定性描述。

### 3. 混凝土浮体的经济性论证正在从「成本」转向「就业」

苏格兰政府与业主给出的全部量化理由都是就业与经济价值（1,200 + 2,900 岗位、£20 亿），**没有一条是 LCOE**。对照 [[漂浮式海上风电LCOE区间]]：**混凝土浮体在成熟市场的推广动力来自产业政策，不来自度电成本。**

**这条对我方报价逻辑的直接影响：在英国、意大利这类市场，「我方浮体更便宜」不构成论据，「我方能让浮体在本地造出来」才是。**
