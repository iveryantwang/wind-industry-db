## 交易结构

| 项 | 内容 |
|---|---|
| 借款人 | Kernel Holding S.A.（乌克兰农业综合企业，卢森堡注册、华沙上市） |
| 贷款人 | **丹麦出口与投资基金 EIFO**（Eksport- og Investeringsfonden，丹麦国家出口与投资机构） |
| 金额 | **1 亿欧元** |
| 项目 | 中乌克兰 94.5MW 陆上风电 + 工业级 BESS |
| 整机 | **Vestas（丹麦），供货 + 安装** |
| 签署日 | 2026-08-27 |
| 资金渠道 | EIFO 支持对乌克兰投资的**专项计划** |

**EIFO 的公开机构定位：为「涉及丹麦企业」的国际项目提供融资。**

## 这条记录的核心：融资渠道即采购渠道

**1 亿欧元的丹麦国家资金，配 21 台丹麦整机。这不是巧合，是 ECA 融资的设计原理。**

出口信用机构存在的目的就是推动本国出口。其贷款条件通常包含最低本国含量要求，因此：

```
获得 EIFO 贷款  ⟹  项目须有实质丹麦供应链  ⟹  整机 = Vestas
```

**整机归属在融资条件谈定时就已决定，采购环节不存在一个开放的比价窗口。**

## 为什么这条对高风险市场特别关键

**战时/战后乌克兰的商业银行项目融资基本不可得。** 在这种环境下，项目能否落地 100% 取决于能否拿到政策性资金。**于是资金的国别属性直接决定了供应链的国别属性 —— 市场竞争被融资竞争替代。**

同样的逻辑适用于本库跟踪的多个新兴市场。把已有样本并排看：

| 项目 | 资金结构 | 整机归属 | 是否可竞争 |
|---|---|---|---|
| **乌克兰 Kernel 94.5MW** | **丹麦 EIFO 单一 ECA** | **Vestas（丹麦）** | **否 —— 随资金锁定** |
| 哈萨克斯坦 Mirny 1GW | EBRD 牵头多国联贷（EBRD、Proparco、DBK、DEG、法兴、QNB、建行、渣打） | 远景 + 三一 | 是 —— 多边资金不绑国别 |
| 哈萨克斯坦 Jambyl 1GW | AIIB | 未定 | 是 |
| 阿曼 JBB 120MW | 项目融资 + 20 年 PPA | — | 是 |

见 [[哈萨克斯坦Mirny 1GW EBRD 5.48亿美元AB贷款结构]]、[[哈萨克斯坦Jambyl 1GW的AIIB融资与美元计价PPA结构]]、[[阿曼JBB 120MW项目融资关闭与20年PPA结构]]。

## 由此得到一条可直接使用的资源分配判据

**在建档任一新兴市场项目时，先问「钱从哪来」，再决定投不投商务资源：**

| 资金来源 | 判读 | 动作 |
|---|---|---|
| **单一国家 ECA**（EIFO、EKF、SACE、Euler Hermes、K-Sure、JBIC 等） | 整机大概率已随资金锁定 | **不投入**，仅登记备查 |
| 多边机构（EBRD、AIIB、EIB、IFC、ADB） | 通常不绑国别，但有采购规则与合规门槛 | **可竞争**，重点核合规资格 |
| 业主自有 / 商业银行 / 本地银团 | 正常市场竞争 | **正常投入** |
| 中方政策性金融 | 我方的对等通道 | **主动争取绑定** |

**这条判据的价值是负向的 —— 它能省掉无效跟踪。** 本库当前 78 条项目记录中，尚无一条系统记录了资金来源属性。

## 对我方的行动含义

**一、乌克兰市场的入口是金融入口，不是商务入口。** 跑开发商与 EPC 的边际收益很低；应盘点中方 ECA（中国进出口银行、中信保）对乌业务的开放状态，以及我方能否进入多边机构（EBRD、EIB）在乌项目的合格供应商名单。

**二、把「资金来源 / 是否 ECA 绑定」列为项目建档的常规记录项。** 与 [[环评阶段的机型容量区间锁定14至22MW]] 提出的「环评容量区间」并列 —— **这两条是本库目前识别出的、最能提前预测整机归属的前置判据，且都发生在询价之前。**

**三、注意这是「风机 + 储能」打包。** 单卖风机在这类结构里连入围都难，参见 [[风储一体化项目的整机与储能打包供货]]。
