## 核心条款

| 项 | 内容 |
|---|---|
| 法律文件 | MASE 司长令 n. 93 del 2/10/2026（更新 n. 82 del 7/8/2026） |
| 首场拍卖 | **2026-12-07** |
| 意向书窗口 | **10-22 → 11-06** |
| 临时保证金 | **11-06** 前交 GSE |
| 首场配额 | 光伏 350MW · **风电 1.5GW**（区间上限 2GW）· 水电 60MW · 余气 2MW |
| NZIA 专项 | 光伏 150MW · **风电 750MW** |
| 第二场 | 约 2027 年 3 月 |
| 风电预资格 | **95 件 / 3,182MW**（[Qualenergia](https://www.qualenergia.it/pro/articoli-pro/fer-x-gw-rinnovabili-prequalifica/)） |
| 机制 | 20 年双向 CfD；>1MW 必须竞价 |

## 对整机厂的影响

1. **首场风电竞争比约 1.6–2.1 倍**（3,182MW 对 1.5–2GW + 750MW NZIA），报价压力会传导给整机
2. NZIA 专项 750MW 的非价格标准是否排斥中国整机 → 直接决定我方在首场能触达的上限，见 [[P0-意大利FERX专项程序供应链韧性门槛核实]]
3. 12-07 中标 → 2027 年上半年整机集中定标
