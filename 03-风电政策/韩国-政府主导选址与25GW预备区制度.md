# 韩国：政府主导海上风电选址制度与 25GW 预备区

## 制度内容

2026-09-02 海上风电发电委员会首次会议通过。核心是把**选址权从开发商手中收归政府**。

**旧模式：** 开发商自行寻找场址 → 自行与居民协商 → 自行办理许可。
**新模式：** 政府用风况、环境、渔业、海上交通、军事等信息识别适宜海域 → 划定预备区 → 地方政府牵头官民协议体取得社区接受 → 划定开发区 → 选定企业承担设计、施工与运维。

### 规模与时间

| 项 | 数值 |
|---|---|
| 预备区划定 | **25GW（2031 年前）** |
| 预期带动装机 | **约 20GW** |
| 2040 年累计目标 | **45GW** |
| 首个预备区 | **2026 年内** |
| 最早开工 | **2033 年** |

### 配套机制

- **选址信息网**：覆盖 301 项海洋空间信息与法规
- **许可整合**：规划阶段与相关部会预审；企业选定后 **42 项许可**依《海上风电法》一并处理
- **存量衔接**：为符合条件的既有项目设立进入《海上风电法》框架的程序
- **官民协议体**：地方政府牵头，自早期介入居民与渔业社区，含收益共享与共存措施

## 影响评估（对整机厂）

**1. 这是一次时点交换：确定性换时间。**

韩国用「更晚但更可预期」替换了「更早但高度不确定」。对开发商是风险下降，对整机厂则意味着**2026–2032 年这一段，韩国海上的新增可争取容量基本为零**，订单只能来自已授标存量项目。

**2. 传统的「先绑开发商」打法效力下降。**

政府主导选址下，「企业选定」被排在开发区划定之后。这意味着在开发商被确定之前，项目就已经有了明确的位置、容量与基本设计。**整机厂能施加影响的窗口从「开发商投标前」前移到了「基本设计阶段」——而这个阶段的对手方是政府与其技术顾问，不是开发商。**

对我方是一个打法上的转变要求：需要在预备区划定与基本设计阶段就提供技术输入（机型容量区间、基础型式、可施工性），这与库内 [[环评阶段的机型容量区间锁定14至22MW]]、[[摩洛哥-首个海上风电可研与开发框架]] 记录的「规则塑造窗口」是同一类动作。

**3. 本地含量压力预计上升。**

政府主导的选址制度通常伴随产业培育目标。韩国已有现成样本：[[Unison-韩国Hanbit 340MW优先供应商与1GW新厂]] —— 本土整机厂借政策周期扩产至 1GW。制度越由政府主导，本土厂商在「企业选定」环节的结构性优势越大。库内 [[P1-韩国1.78GW授标项目拆分与LCR]] 的判断应据此加强而非放松。

**4. 与本库既有韩国政策条目的关系。**

[[韩国-2026上半年海上风电拍卖机制]] 记录的是**拍卖侧**规则（谁以什么价格拿到 CfD），本条记录的是**选址侧**规则（项目在哪里、由谁定）。两者并存不冲突：预备区划定后仍需经企业选定，拍卖机制预计继续适用于该环节。**两个口径并列保留，不合并。**
