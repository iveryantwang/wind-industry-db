## 政策内容

**2026-08-25**，印度 **MNRE** 就西亚局势导致的项目延误发布指导意见，起因是开发商的集体陈情。

| 项 | 内容 |
|---|---|
| 适用对象 | 各可再生能源实施机构（REIA）、采购机构、各邦/联邦属地主体 |
| 点名的 REIA | **SECI、NTPC、NHPC、SJVN** |
| 顺延幅度 | **最长 4 个月** |
| 顺延的日期 | 供电开始日（SCSD）／并网日（SCD） |
| 合资格范围 | 计划或已延期日期落在 **2026-02-28 当日及之后**的项目 |
| 法律定性 | **财政部已明确西亚局势按「战争」认定**，通常构成 PPA 项下不可抗力事件 |
| 救济方式 | 按各 PPA 的不可抗力条款与程序执行 |

注意措辞是「建议考虑给予（advised to consider granting）」，**不是自动顺延**，需逐项目按 PPA 条款申请。

## 影响评估（整机厂视角）

**这条政策的实质是把交付延误的风险在业主与供应商之间重新分配了一次，而分配结果对供应商不利。**

链条是这样的：

```
西亚局势 → 海运/物流扰动 → 设备到货延迟 → 项目并网延迟
                                    ↓
业主：有 MNRE 背书 + PPA 不可抗力条款 → 向采购方申请顺延，风险已转出
整机厂：供货合同的交付节点若未同步展期 → 逾期罚则仍在自己身上
```

**业主的免责路径已经打通，供应商的没有。** MNRE 的文件针对的是 PPA（业主与采购方之间），不针对 EPC / 供货合同（业主与整机厂之间）。除非供货合同里有对应的不可抗力条款并被同样认定，否则**顺延的好处归业主，罚则的风险仍归供应商**。

**对我方的两条动作口径：**

1. **投印度标的时，供货合同的不可抗力条款必须与 PPA 口径对齐** —— 明确写入「若业主依 MNRE 指导意见获得 SCSD/SCD 顺延，供货节点相应顺延」的联动条款。这是本条最直接的可执行输出，应写进 [[P0-印度NTPC 600MW WTG投标9月15日截止]] 与 [[P0-印度TerraClean200MW投标截止9月1日]] 的投标文件审查清单
2. **印度在跑项目的交付节奏普遍后移约一个季度** —— 这对我方是中性偏有利的：给了准入合规（ALMM/RLMM）更多缓冲时间，但也意味着任何基于原并网日的排产假设都要重算

**一个需要留意的次生效应：** 西亚物流扰动对**进口整机**的影响大于对本地产能的影响。Suzlon、Inox 的本地供应链受冲击小，进口机组受冲击大。**这条政策在缓解延误后果的同时，也在无声地强化「本地产能更可靠」的叙事** —— 与 [[印度发电机与传动链本地化产能]] 中记录的 Flender 本地化动作叠加，印度市场的本地化压力在两个方向同时上升。
