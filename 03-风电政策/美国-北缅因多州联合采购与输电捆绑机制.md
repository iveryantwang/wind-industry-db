## 机制要点

**这是一个「发电 + 输电捆绑、多州分摊成本」的采购机制，本库北美条目中首次出现。**

| 要素 | 设计 |
|---|---|
| 招标标的 | **发电与输电同一轮次分别授予** |
| 发电中选 | Clearway 800MW 陆上风电，授电量 + 绿证 |
| 输电中选 | Avangrid Networks 1,200MW 线路，终点 Haynesville |
| **条件关系** | **发电授予以输电落地为前提** |
| 参与方 | 缅因、马萨诸塞、康涅狄格、佛蒙特、罗德岛**五州** |
| 协调内容 | 成本分摊、并网标准、项目监管 |
| 成本分摊 | 缅因州承担输电成本**不到 11%** |
| 余量安排 | 线路剩 **400MW**，**计划另发招标** |

输电方案的中选理由是**最大限度利用既有走廊**且开发商**已取得几乎全部路权** —— 委员会明确将「在商业上合理的时间内可开发」作为评审依据。

## 与本库既有招标机制的对比

| 机制 | 授予对象 | 整机窗口的决定因素 |
|---|---|---|
| 英国 CfD（[[英国-AR8差价合约招标]]） | 电价合约 | 中标后开发商自行招标 |
| 台湾区块开发（[[台湾-第三阶段区块开发第三期规则]]） | 场址 + 并网容量 | **产业关联方案**（整机在申请阶段就已绑定） |
| 印度 SECI（[[印度-SECI-2GW ISTS风电招标]]） | 电价 + 并网 | 中标后 EPC 总包，整机随总包 |
| 哈萨克斯坦拍卖（[[哈萨克斯坦-2026可再生能源拍卖时间表]]） | 电价上限 | 中标方自定 |
| **北缅因（本条）** | **电量 + 绿证，附输电条件** | **输电项目的进度** |

**北缅因这一形态的特点：整机窗口不由发电项目自身的节奏决定。** 输电线路的路权、许可、FID 全部完成之前，发电侧的整机采购不会真正启动。

**这对我方的方法论含义（超出美国本身）：** 凡是「发电中标附带电网前置条件」的市场，跟踪对象应是**电网项目里程碑**，而不是发电项目公告。这与库内 [[台湾Formosa6企业购电协议覆盖率与专案融资前提]]（跟售电覆盖率）、[[匈牙利-风电并网容量分配招标702MVA]]（跟并网容量分配）属于同一类识别方法 —— **整机窗口的先行指标往往不在整机侧。**

## 本库对美国的处置不变

本条不改变库内对美国市场的既定判断。理由已记录在 [[美国-税收抵免退坡下的近期交付冲刺与前期管道走弱]]、[[美国-BOEM对已核准项目的发回重审机制]]、[[P2-美国海上风电退出后的产能与订单外溢]]。

**本条按低频观察项处理，不新建 P 级判断。**
