>
> **在用：方案 A（Cowork 定时任务）。方案 B 已停用。**
>
> `99-系统/scripts/daily_update.bat` 已改为停用提示脚本并直接退出，
> 原内容完整备份在同目录 `daily_update.bat.disabled`。
>
> **停用原因：** 两套流程都会执行 `git add / commit / push`，同时运行会争抢
> `.git` 锁文件（`HEAD.lock`、`index.lock`、`refs/remotes/origin/main.lock`），
> 导致提交或推送失败，且残留的锁文件会持续影响后续运行。
>
> **计划任务无需处理。** 2026-08-02 已核查，`schtasks /Query /TN "风电行业数据库每日更新"`
> 返回「系统找不到指定的文件」—— 该计划任务**从未注册过**，方案 B 一直只停留在文档层面。
> 所以停用 bat 之后没有任何残留的自动调用，无需再做清理。

### 注册为计划任务

管理员 PowerShell 里执行：

```powershell
$bat = "D:\works\2026\亚太区工作\风电行业数据库\风电行业数据库\99-系统\scripts\daily_update.bat"

schtasks /Create `
  /TN "风电行业数据库每日更新" `
  /TR "`"$bat`"" `
  /SC DAILY /ST 02:00 `
  /RL HIGHEST /F
```

补充设置（可选，让开机后错过的任务补跑）：

```powershell
$t = Get-ScheduledTask -TaskName "风电行业数据库每日更新"
$t.Settings.StartWhenAvailable = $true
$t.Settings.ExecutionTimeLimit = "PT30M"
Set-ScheduledTask -InputObject $t
```

验证 / 手动触发 / 删除：

```powershell
schtasks /Query /TN "风电行业数据库每日更新" /V /FO LIST
schtasks /Run   /TN "风电行业数据库每日更新"
schtasks /Delete /TN "风电行业数据库每日更新" /F
```

## Excel 快照

每次自动更新后会在 vault 根目录生成 `风电行业数据库_最新.xlsx`，版式沿用原储能数据库
（深蓝标题栏 + KPI 卡片 + 区域分布条 + 7 张带筛选器的数据表）。

手动导出：

```powershell
cd "D:\works\2026\亚太区工作\风电行业数据库\风电行业数据库"
python 99-系统\scripts\export_excel.py . "风电行业数据库_最新.xlsx"

# 或带日期戳存档
python 99-系统\scripts\export_excel.py
```

若本机缺 openpyxl：`pip install openpyxl`

**Excel 是单向导出，不是双向同步。** 在 Excel 里改数据不会回写 Obsidian，下次导出会被覆盖。
数据的唯一真实来源是 Obsidian 笔记。

## 故障排查

| 症状 | 检查 |
|---|---|
| 表格没更新 | 手动跑 `python rebuild_tables.py`，看是否报 `未找到标记` —— 说明索引页的 `<!-- AUTO-TABLE:START -->` 被误删 |
| 新笔记不进表 | YAML 里 `type` 拼错/缺失；或文件名以 `_` 开头 |
| 日期排序乱 | 日期不是 `YYYY-MM-DD` 格式 |
| 容量排序不对 | `capacity_mw` 写了单位，应只写数字 |
| 发布页表格空白 | 你看的是页面底部 Dataview 块（Publish 不渲染），往上翻看「全量表格」 |
| bat 无输出 | 看 `99-系统\日志\<日期>.log`；大概率是 `claude` 未登录或不在 PATH |
| 中文乱码 | bat 已含 `chcp 65001`；若仍乱码，任务计划里勿勾选「使用旧版控制台」 |
