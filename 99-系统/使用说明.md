# 使用说明

## 一、给「只看不改」的同事

打开分享的网址即可，**不需要安装任何软件**。

- 首次打开会要求输入你的邮箱 → 收一封验证码邮件 → 输入验证码即进入
- 验证一次可用 24 小时
- 每个板块页面顶部就是完整表格，点标题进详情页
- 左侧有搜索框，可全站搜索
- 内容每天凌晨 02:00 自动更新，早上打开就是当天的

网址打不开或收不到验证码，找 Zhenyu 把你的邮箱加进白名单。

### 二、客户与项目机会库怎么读

这是整机厂视角的项目库，两列最重要：

**「机会」列**

| 值 | 含义 |
|---|---|
| 🟢 高 | 整机未定 + 容量 ≥100MW + 阶段合适 —— **可争取** |
| 🟡 中 | 整机未定但阶段过早或容量偏小 |
| ⚪ 低 | 已开工且整机大概率锁定，或市场结构上难进 |
| ⚫ 已失单 | 整机已被竞对拿下 |

**「整机商」列**

显示 `未定 ★` 就是机会所在 —— 这个项目的整机还没定标。
已填厂商名的，说明已被该厂商拿下。

### 七、战略判断怎么读

| 优先级 | 含义 |
|---|---|
| P0 | 行动窗口 **4 周内即将关闭** —— 整机定标在即、投标截止临近、已开工但整机未定 |
| P1 | 本月内应推动 |
| P2 | 持续观察 |

每条都有「建议行动」和「行动窗口」两列，是可以直接派活的粒度。

## 三、自动更新在做什么

每天凌晨 **02:00**：

1. **14–18 次检索**，覆盖欧洲（含意大利）、北美、亚太（含柬埔寨、老挝）、中亚（含哈萨克斯坦）、澳洲、拉美
2. 按类别写入七个板块，**全部板块都自动生成**，包括客户与项目、战略判断
3. 重建所有索引页的静态表格 + 总览统计
4. 导出 Excel 快照 `风电行业数据库_最新.xlsx`
5. 推送到 GitHub，站点自动重新构建上线
6. 在 [[更新日志]] 追加一条记录

## 四、想修改内容 / 不想被自动覆盖

需要在本机装 [Obsidian](https://obsidian.md)（免费）并打开这个 vault。

### 锁定一条笔记

在笔记最上方的 YAML 里，把

```yaml
manual: false
```

改成

```yaml
manual: true
```

**改完这条笔记就被锁定了，自动任务永不修改它。** 适用于：

- 你补充了内部信息（我方对接人、报价区间、沟通记录）
- 你修正了自动检索的错误判断
- 你手动调整了某条的优先级

### 新增一条

`Ctrl+N` 新建，存到对应板块文件夹 → `Ctrl+P` → `Templates: Insert template` → 选对应模板
→ 填 YAML → 把 `manual` 改成 `true`。

字段含义见 [[字段规范]]。

> **关键**：`type` 那一行不能删或改，表格靠它识别归属。

## 五、为什么表格是「静态」的

站点和 Obsidian Publish 都不渲染 Dataview 查询，发布出去会一片空白。
所以采用双轨：

| | 本地 Obsidian | 在线站点 |
|---|---|---|
| 页面顶部「全量表格」 | ✅ 静态表格 | ✅ 静态表格 |
| 页面底部 Dataview 块 | ✅ 可任意筛选排序 | ❌ 构建时已剥离（正常） |

想在本地用 Dataview 做自定义筛选：设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜索
`Dataview` → 安装启用。不装也能看静态表格。

## 六、手动重建表格 / 导出 Excel

刚改了一批笔记想立刻看到效果，不用等第二天：

```powershell
cd "D:\works\2026\亚太区工作\风电行业数据库\风电行业数据库"

python 99-系统\scripts\rebuild_tables.py .
python 99-系统\scripts\export_excel.py . "风电行业数据库_最新.xlsx"
```

> Excel 导出时如果那个文件正开在 Excel 里，会锁定写入失败 —— 脚本会自动改存成带时间戳的
> 备用文件名并提示你。关掉 Excel 再跑就能覆盖。

想让站点也立刻更新：

```powershell
git add -A && git commit -m "manual update" && git push
```
