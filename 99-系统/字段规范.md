# 字段规范

YAML 字段名用英文（Dataview 与脚本更稳定），表格显示中文。
**`type` 字段决定笔记归属哪张表，不可省略。**

## 通用取值约定

| 字段 | 取值 |
|---|---|
| `region` | 欧洲 / 北美 / 亚太 / 拉美 / 中东非 / 全球 |
| `country` | 具体国名，跨国填「欧盟」「欧洲（多国）」等 |
| `segment` | 陆上 / 海上 / 漂浮式 / 通用 |
| `importance` | 高 / 中 / 低 |
| `date` `issued` | `YYYY-MM-DD`，务必用连字符，否则排序失效 |
| `capacity_mw` | 纯数字，不带单位，如 `1200`。未知留空 |

## 1 每日新闻 `type: news`

| 字段 | 含义 | 必填 |
|---|---|---|
| `date` | 新闻日期 | ✅ |
| `title` | 标题 | ✅ |
| `summary` | 一两句摘要 | ✅ |
| `region` `country` | 区域 / 国别 | ✅ |
| `segment` | 陆上/海上/漂浮式/通用 | |
| `topic` | 数组：招标/并网/订单/供应链/事故/人事/其他 | |
| `source_name` `source_url` | 来源名 / 原文链接 | ✅ |
| `importance` | 高/中/低 —— 「高」会进总览高亮区 | ✅ |

## 2 客户与项目 `type: project` 🤖自动

| 字段 | 含义 |
|---|---|
| `customer` | 客户 / 业主名称 |
| `project` | 项目名称 |
| `capacity_mw` | 装机容量 MW |
| `unit_mw` | 单机容量 MW |
| `turbine_count` | 台数 |
| `turbine_model` | 机型，如 `SG 14-236 DD` |
| `segment` | 陆上 / 海上 / 漂浮式 |
| `status` | 前期 / 核准 / 招标中 / 已中标 / 在建 / 已并网 |
| `oem` | 整机商 |
| `cod_year` | 预计并网年份 |
| `owner_contact` | 我方对接人 |
| `opportunity` | **我方机会等级**：高 / 中 / 低 / 已失单 |
| `capex` | 投资规模（若披露，带货币单位的字符串） |
| `manual` | 默认 `false`。改成 `true` 可锁定此笔记，自动任务不再修改 |
| `first_logged` `updated` | 首次记录 / 最后更新日期 |

## 3 风电政策 `type: policy`

`policy` 政策名称 · `issued` 发布日期 · `issuer` 发布机构 ·
`summary` 核心内容 · `impact` 影响评估 · `impact_level` 高/中/低 · `source_url`

## 4 竞争对手 `type: competitor`

`competitor` 对手名 · `event_type` 订单/中标/产能/技术/合作/财报/人事 ·
`counterparty` 签约客户 · `contract_value` 合同金额（带货币符号的字符串）·
`capacity_mw` · `turbine_count` · `date` · `source_url`

## 5 技术方案 `type: tech`

`solution` 方案/场景名 · `description` 描述 · `use_case` 应用场景 ·
`provider` 提供方 · `maturity` 研发/样机/示范/商用 · `date` · `source_url`

## 6 投资财务 `type: finance`

`subject` 项目或模型名 · `capex` 投资规模 · `irr` 回报率 · `lcoe` ·
`biz_model` PPA/CfD/绿证/上网电价/自持 · `funding` 资金来源 · `date` · `source_url`

## 7 战略判断 `type: strategy` 🤖自动

`priority` P0/P1/P2 · `owner_party` 业主/开发商 · `project` · `capacity_mw` ·
`action` 建议行动（一句可执行的话）· `rationale` 判断依据 · `deadline` 行动窗口 ·
`status` 待启动/进行中/已完成/已放弃 · `manual` 默认 false

### 优先级判定口径

| 级别 | 含义 |
|---|---|
| `P0` | 行动窗口 4 周内即将关闭 —— 整机定标在即、投标截止临近、已开工但整机未定 |
| `P1` | 本月内应推动 |
| `P2` | 持续观察 |

### 机会等级判定口径（`opportunity`）

| 等级 | 判定条件 |
|---|---|
| `高` | 整机未定 **且** 容量 ≥100MW **且** 阶段在核准/招标中/已中标/环评后期 |
| `中` | 整机未定但阶段过早（前期/环评早期）或容量偏小 |
| `低` | 已开工且整机大概率已锁定，或市场结构上我方难进入 |
| `已失单` | 整机已由竞对拿下（须同时在 `04-竞争对手` 建对应记录） |

## 常见错误

| 症状 | 原因 |
|---|---|
| 自动任务改了我手写的内容 | 该笔记 YAML 里没写 `manual: true` |
| 笔记不出现在表格里 | `type` 拼错、缺失，或笔记文件名以 `_` 开头 |
| 日期排序乱 | 日期写成 `2026/7/8` 或 `7月8日`，必须 `2026-07-08` |
| 容量列排序不对 | `capacity_mw` 写了 `1200MW`，应只写 `1200` |
| YAML 报错 | 值里含 `:` 或 `#` 未加引号 → 用 `"..."` 包起来 |
