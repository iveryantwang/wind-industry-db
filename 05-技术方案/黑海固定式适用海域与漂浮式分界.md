## 技术要点

| 口径 | 数值 |
|---|---|
| 黑海（罗马尼亚海域）技术可开发潜力 | 约 76GW |
| 其中固定式可行 | 约 22GW |
| 其中需漂浮式 | 约 54GW |
| 平均风速 | >7.5 m/s |
| 一期特许海域基础型式 | **全部固定式**（能源部明确「以现有海上技术即可实施」） |
| 一期规模 | 1.9GW + 600MW + 600MW = 3.1GW |

## 对我方方案的含义

**1. 罗马尼亚一期不需要漂浮式版本机型。** 这是本条最直接的结论。此前我方对罗马尼亚黑海的技术可行性判断挂在 [[P0-漂浮式15MW机型资格内部定性]] 之下（该条已标为「已放弃」），现在解除依赖 —— 一期三片场址用我方现有固定式平台即可投。

**2. 但固定式只占黑海潜力的 29%，长期需要漂浮式。** 三期 6GW 已明确为「固定式 + 漂浮式混合」。这意味着黑海市场的完整覆盖仍以漂浮式能力为前提，只是时间点被推后到 2030 年代。短期按固定式打，中期漂浮式能力仍是留在这个市场的门票。

**3. 平均风速 >7.5 m/s 属中高风速场址。** 与我方低风速高切变优化机型（见 [[低风速高切变场址的3.9MW级机型与156米混塔组合]]）不匹配，应按中高风速海上平台配置，叶轮直径不必推到极限，可用较高额定容量 / 中等叶轮的组合优化 CAPEX。

**4. 与深水基础选型的衔接。** 黑海固定式可行区间与我方在 [[深远海40至68米水深固定式基础选型]] 中的适用范围需要核对 —— 若一期场址水深落在 40–68m 区间，导管架方案的性价比可能优于单桩，应在早期就给出两套基础方案的对比，而非等开发商选定后再配合。
