## 设计要点

| 项 | 内容 |
|---|---|
| 目标机组 | **18MW 及以上** |
| 回复机制 | 中央配重 + **三组铰接系泊框架（AMF）** + 近垂直系泊缆；**被动回复，无主动压载** |
| 本代结构改动 | 三脚架支撑 · 升级 AMF · 修改船体几何 → 改善水动力与载荷分布，减重且提高损伤容限 |
| 安装维护 | **拖航进港（tow-to-port）**，降低对专用海上船机的依赖 |
| 制造 | 模块化钢结构，利用既有港口设施 |

## 台风工况的公开设计门槛（本条最有价值的部分）

**这是目前可查到的、针对台风海域漂浮式最完整的一组公开校核条件：**

| 校核项 | 数值 |
|---|---|
| 50 年一遇风速 @ 轮毂高 **155m** | **59.8 m/s** |
| 50 年一遇有效波高 | **14.2m** |
| 横摇 / 纵摇 | **< 5 度** |
| 塔顶加速度 · 塔基载荷 | 在项目设计准则内 |

**把这组数字当作准入门槛来用。** 台湾、日本、越南、菲律宾的漂浮式项目在技术预选阶段会要求整机方给出对应工况下的机组响应。**我方 15MW 级及以上机型若无该量级的台风工况校核与公开可引用的结论，会在技术预选阶段被直接筛除，而不是在报价阶段落后。**

## 对我方（整机厂）的三条约束

1. **整机侧的台风工况能力必须先于商务动作准备好。** 本库 [[15MW级抗震设计固定式海上机组]] 已记录地震工况的同类问题 —— 台风工况是亚太漂浮式的等价门槛。
2. **浮体按 18MW+ 设计，整机主力在 15MW 档 —— 存在一代差。** 浮体方用设计容量给整机方设定了升级时间表。参见 [[环评阶段的机型容量区间锁定14至22MW]]：环评阶段锁定容量区间的做法正在与浮体设计容量同步抬高。
3. **无主动压载 + 拖航进港，对整机的界面影响是双向的。** 好处：整机可在码头总装，减少海上作业（[[张力腿平台TLP漂浮式整机码头总装一次拖航]]、[[漂浮式整机码头总装的港口吞吐约束]]）。约束：被动回复意味着运动响应完全由结构与系泊决定，**整机控制策略必须与浮体动力学联合调参，不能沿用固定式的控制器。** 这要求在浮体选型确定后就介入，而不是供货前介入。

## 供应链绑定风险

**Gazelle 与天顺风能（Titan Wind Energy）2025-10 签署备忘录，约定按天顺的海上装备与制造标准优化该平台。**

读数：**该平台的钢结构与制造界面正在向中国供应链靠拢。** 若它落地亚洲台风海域项目，中国厂商在浮体—整机界面上会先天占优。**这是「中国产能出海」的一条本库此前未记录的路径 —— 不是整机直接中标，而是通过绑定欧洲浮体设计方，把制造标准前置进项目。**
