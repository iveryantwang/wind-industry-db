# 60–90 米水深的固定式基础（BC90 类）

## 技术定位

| 项 | 内容 |
|---|---|
| 提供方 | **Neretek** —— Wood Thilsted 与 COP Frontier 合资，**2026-07-08 成立** |
| 负责人 | Jonathan Cole，前全球风能理事会（GWEC）主席 |
| 产品 | **BC90 固定式基础** |
| 目标水深 | **60–90 米** |
| 制造 | **本地供应链 + 现有港口设施**，不依赖大型专用安装船 |
| 成本主张 | CAPEX **显著低于**同深度的深水单桩或导管架 |
| 首发市场 | 英国 |
| 成熟度 | **研发阶段**，尚无实机 |

Cole 的核心主张：BC90 可以消除「现有固定式设计的能力上限」与「尚未商业化的漂浮式」之间的空档期，把 60–90 米这一段称为**「其他深水（other deepwater）」**。

## 本库的深度带覆盖：这一条补上了一个真实的缺口

| 水深带 | 本库既有条目 | 状态 |
|---|---|---|
| ≤40 m | 常规单桩，见 [[大直径单桩量产产能年200支节奏]]、[[南欧XXL单桩本地化产能11米直径105米]] | 覆盖充分 |
| 40–68 m | [[深远海40至68米水深固定式基础选型]] | 有条目 |
| **60–90 m** | **此前为空白** | **本条补上** |
| >90 m | 漂浮式，见 [[漂浮式半潜平台商业化运维]]、[[张力腿平台TLP漂浮式整机码头总装一次拖航]] | 覆盖充分 |

**60–90 米这一段此前在我方判断中被默认划给漂浮式。**这不是我方独有的偏差 —— 整个行业的默认分界大致在 60 米。BC90 若成立，这条分界线会往深水方向推 30 米。

## 对我方的含义

**这是一条会改变「该报什么机型」的技术信号，不是一条供应链新闻。**

### 一、直接影响我方在中深水标的上的机型选择

固定式与漂浮式对整机的要求不同：漂浮式需要通过浮体—塔筒耦合载荷校核（我方在这一项上的结论至今未闭合，见 [[P0-漂浮式15MW机型资格内部定性]]，状态已放弃），固定式则可沿用现有海上机型的载荷包络。

**如果 60–90 米海域重新归类为固定式候选，我方在这些标的上的技术门槛从「需要漂浮式版本机型」降到「现有海上机型即可」。**这对我方是明确的利好 —— 我方的短板正在漂浮式一侧。

### 二、需要立即复核的在库标的

以下条目的水深若落在 60–90 米区间，其基础路线判断需要重做：

- [[黑海固定式适用海域与漂浮式分界]] —— 本库已有的分界结论直接受影响，**这是最优先复核项**
- [[罗马尼亚-能源部-黑海一期3.1GW]]
- [[意大利-Nereus-HyMed]]、[[意大利-Avenhexicon-Sardinia Nord East]]、[[意大利-Renexia-Sicilian Strait]] —— 地中海侧多个标的按漂浮式规划，需核实实际水深
- [[英国-Nadara-Bellrock 1.8GW漂浮式]]、[[英国-EDF-ESB-住友-Gwynt Glas 1.5GW漂浮式]]

### 三、不能过度反应的理由

**BC90 目前处于研发阶段，没有实机，没有已授标项目，Neretek 成立仅两个月。**

具体的不确定性：

| 未知项 | 为什么关键 |
|---|---|
| 单位造价的量化区间 | 「显著低于」无数字，无法做度电成本对比 |
| 承载的机型容量上限 | 若只支持 15MW 以下，对我方大兆瓦路线无意义 |
| 安装工艺与工期 | 「不依赖大型专用安装船」是主要卖点，但未见工艺细节 |
| 首个示范项目与时间表 | 无 |

**在拿到这四项之前，不应据此改动任何在库标的的基础路线判断，只做水深复核与跟踪。**
