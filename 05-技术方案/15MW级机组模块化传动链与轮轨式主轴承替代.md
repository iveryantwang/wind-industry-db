## 技术要点

**LIGHTWIND 要解决的是一个我方在做大兆瓦机型时同样会撞上的问题：功率上去以后，主轴承成了尺寸、重量与维护成本的三重瓶颈。**

| 项 | 内容 |
|---|---|
| 目标 | 基于 **OptiGen** 概念的 **15MW 以上**海上机组 |
| 核心改动 | **以贴近发电机气隙布置的轮轨（wheel-and-rail）系统，替代常规大尺寸主轴承** |
| 针对的痛点 | 功率提升带来的**结构尺寸与载荷增大、部件重量上升、海上维护要求与成本上升** |
| 设计基准 | **IEA Wind 15MW 参考机组** |
| 已做的工作 | 识别疲劳最关键部件；分析轮轨工况、作用载荷与所需材料；搭建**加速耐久试验台** |
| 动态验证 | **Beat 1.1 六自由度平台**（IDOM 研制，位于 **Fraunhofer IWES 汉堡基地**）复现机械系统动态响应 |
| 进度 | **首轮试验已完成**，正据结果改进并准备**第二轮** |

## 对我方的三点含义

### 一、大尺寸主轴承是一个行业共识级的瓶颈，而不是某一家的工程问题

**LIGHTWIND 把问题定义得很清楚：功率等级上升 → 结构尺寸与载荷增大 → 部件重量上升 → 海上维护要求与成本上升。这四步是连锁的，而主轴承是链条上最集中的一环。**

**我方在 15MW 以上机型的方案中，主轴承走的是什么路线、重量与可更换性如何，应当有一个与之对标的书面答案。** 本库此前的技术条目里，[[11MW级海上机组含塔架总包供货]]、[[15MW级抗震设计固定式海上机组]]、[[环评阶段的机型容量区间锁定14至22MW]] 讨论的都是整机层面的容量与适配，**传动链架构这一层是空的。**

### 二、机舱重量的约束正在从「运输吊装」变成「浮体承载」

**这一条与 09-09 的 [[轻量化下风向漂浮式平台的整机界面约束]] 直接咬合。**

X1 Wind 一类轻量化浮体压缩结构裕度，**把机舱与塔筒重量上限变成了硬约束而非优化目标**。LIGHTWIND 从整机侧减重，正好对上浮体侧的重量上限。

**含义：15MW 以上机型的漂浮式版本，减重不是为了省成本，是为了取得准入资格。** 我方若在这一层没有动作，[[P0-漂浮式15MW机型资格内部定性]] 卡住的那个问题（有没有通过浮体—塔筒耦合载荷校核的 15MW 级版本）**即使回答了「有」，也可能因为重量超出轻量化浮体的包线而仍然进不去。**

**这是该 P0 被外部事实点名的第五次，且第一次是从整机内部结构的角度点名。**

### 三、验证设施本身是一个门槛

**Fraunhofer IWES 的 Beat 1.1 六自由度平台 + 加速耐久试验台 —— 欧洲的传动链新架构在进入样机之前，先在公共研究设施上完成了两轮验证。**

这与 09-07 的苏格兰 BW Ideol 案例（公共资金直接介入浮体 FEED）、09-08 的 DNV JIP（八家供应链企业联合研究）是同一模式：**欧洲用公共设施与联合研究项目，把新技术的验证成本社会化，再由参与方分享结果。**

**我方不在这些项目里。** 含义有两面，本库并列记录：

- **不利：** 对手的新架构在进入市场时已带着第三方公共设施的验证数据，我方的同类方案只有自证
- **可行的应对：** 这类欧洲项目通常对外部参与方开放（付费或联合研究形式），**参与本身就是取得第三方验证背书的路径** —— 这比自建试验台快且便宜
