## 方案要点

| 项 | 内容 |
|---|---|
| 做法 | **取消过渡段**，塔筒底段**直接安装于单桩顶** |
| 首个规模化案例 | **Zeevonk 一期 1GW，69 根单桩**（2026-09-16 定标） |
| 制造方 | **EEW Special Pipe Constructions** |
| 业主 | **Vattenfall + CIP** |
| 来源声称收益 | 省钢材、降原材料消耗、简化物流、减少制造与安装碳排 |
| 附加 | 1 根基础采用高再生比例钢材 |
| 推算单机容量 | 1GW ÷ 69 ≈ **14.5MW 级**（本库推算，非来源口径） |

## 传统链条 vs 无过渡段

| | 传统 | 无过渡段 |
|---|---|---|
| 结构 | 单桩 → **过渡段** → 塔筒 | 单桩 → **塔筒** |
| 垂直度偏差 | 由过渡段的灌浆或螺栓连接**吸收** | **无缓冲，直接传导至塔筒法兰** |
| 附属结构 | 爬梯、平台、J 型管挂在过渡段上 | 需重新分配到单桩或塔筒 |
| 塔筒底段 | 通用设计可用 | **须按单桩接口定制** |

## 为什么这对整机厂是界面问题，不是基础商的内部优化

**三条，按对我方的严重程度排序：**

### 1. 施工公差风险从基础侧转移到整机侧

过渡段是基础与整机之间的**缓冲层**。取消之后，打桩垂直度的偏差没有地方吸收，**直接落在塔筒法兰的对接面上**。

这在合同上是一次风险再分配：**整机厂要么在合同里明确接受的垂直度公差带并据此加价，要么承接原本不属于自己的施工风险。** 这一条必须在报价阶段就写进界面协议，不能留到现场。

### 2. 塔筒底段项目定制化，通用件优势消失

塔筒底段要为特定单桩的顶法兰设计 —— **不是通用塔筒能直接用的**。对依赖塔筒标准化摊薄成本的厂商，这是成本项；对已具备定制能力的厂商，是壁垒。

### 3. 这项能力正在变成北海项目的资格条件

无过渡段不是孤例。结合本库既有记录：

- [[大直径单桩量产产能年200支节奏]] —— 单桩正在向更大直径、更高产能走
- [[南欧XXL单桩本地化产能11米直径105米]] —— 11 米直径、105 米长已量产
- 本条 —— 大直径单桩 + 取消过渡段

**方向一致：把结构层数减少、把单桩做得更大更强。** 在这个方向上，**能不能做单桩直连接口，会从「技术亮点」变成「投标资格」**，与 [[分段叶片与山地偏远场址的机型准入]] 是同一类演化。

## 与整机定标时序的关系（一条判断，不是事实）

**无过渡段设计要求塔筒底段与单桩接口协同设计 —— 这通常意味着整机商与基础商是同期敲定的，不会等基础签完再选整机。**

所以：**看到一个项目的单桩用无过渡段设计且已定标，就应默认整机大概率也已锁定，即便未公开。** 这条推论已写入 [[荷兰-Vattenfall-CIP-Zeevonk 1GW一期]] 的机会判断（定为「低」而非「高」）。
