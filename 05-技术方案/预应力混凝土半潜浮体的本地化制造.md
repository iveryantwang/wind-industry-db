# 预应力混凝土半潜浮体的本地化制造

## 方案要点

| 项 | 内容 |
|---|---|
| 名称 | **Raijin Float** |
| 提供方 | Japan Blue Energy（JB Energy，日本） |
| 型式 | **预应力混凝土半潜式** |
| 设计前提 | **就地制造** —— 利用项目所在国的水泥工业、船厂、海工工程能力、港口基础设施 |
| 首个应用 | 巴西 **Aura Sul Wind** 示范项目，水深约 44m，离岸约 65km |
| 承载机型 | **明阳智能 MySE 18MW**（建成后为全球单机最大漂浮式机组） |
| 成熟度 | **示范**（已获 IBAMA 环境许可，目标 2030 年前安装） |
| 配套研究 | 2026-09-04 ABS 签约提供**浮体初步退役策略**与港口减排研究 |

## 与库内既有漂浮式浮体路线的对比

| 路线 | 库内条目 | 制造依赖 | 适用市场特征 |
|---|---|---|---|
| 钢制半潜 | [[漂浮式半潜平台商业化运维]] | 专业钢结构产能 + 远洋运输 | 有成熟海工钢结构基地的市场 |
| 张力腿 TLP | [[张力腿平台TLP漂浮式整机码头总装一次拖航]]、[[明阳智能-CNOOC Anlan 16MW张力腿漂浮式投运]] | 专业产能 + 系泊系统 | 深水、系泊条件好 |
| **预应力混凝土半潜** | **本条** | **水泥 + 常规船厂 + 港口** | **钢结构产能不足但基建产业成熟的新兴市场** |

**混凝土路线的核心价值不是成本，是本地含量。**它把浮体制造从「需要专门的海工钢结构基地」降格为「本国水泥厂 + 常规船厂就能干」，这直接回应了新兴市场最关心的本地就业与产业带动诉求。

## 对我方的含义

### 一、这是一条我方在本地含量竞争中缺失的弹药

库内 [[产能出海的市场准入前置条件]]、[[本地整机厂技术引进与产能承诺的组合打法]]、[[整机出海从设备供货到全链条方案]] 三条讨论的都是**整机侧**的本地化承诺。**浮体侧的本地化此前不在我方方案库里。**

在漂浮式标的的评审中，本地含量往往按项目总投资的比例计算，而**浮体在漂浮式项目 CAPEX 中的占比通常高于整机**。这意味着：**能提供本地可制造浮体方案的投标方，在本地含量得分上有结构性优势，与整机产地无关。**

### 二、明阳已经用上了这条弹药，我方没有

见 [[明阳智能-巴西AuraSulWind 18MW漂浮式整机供货]]。明阳自己不做浮体，但它**接受了 JB Energy 的混凝土浮体并完成了耦合适配**。这意味着：

- 明阳已有一次混凝土浮体—整机耦合载荷校核的实践经验
- 下一次遇到混凝土浮体标的，明阳的边际适配成本比我方低
- 我方若只有钢制半潜的适配经验，每遇一次都要从头论证

### 三、优先适用的市场清单

按「水泥工业与船厂较好、钢结构海工产能不足、本地含量要求高」三条筛，本库内的相关标的：

| 市场 | 相关在库条目 | 适配价值 |
|---|---|---|
| 巴西 | [[巴西-JBEnergy-AuraSulWind 18MW漂浮式示范]] | 已被明阳先手 |
| 意大利（地中海漂浮式） | [[意大利-Renexia-Sicilian Strait]]、[[意大利-Nereus-HyMed]]、[[意大利-GreenIT-CIP-三个漂浮式项目]] | **本地含量是意大利拍卖的实质考量项** |
| 摩洛哥 | [[摩洛哥-MASEN-Essaouira 1GW海上风电]] | 处于可研期，规则可塑造 |
| 韩国 | [[韩国-PacificoEnergy-Jindo二期2130MW]] | LCR 要求高，但船厂钢结构产能充足，混凝土路线优势不明显 |

**意大利是最值得投入的一个** —— 五个重点国家之一、多个漂浮式标的在环评中、本地含量是拍卖实质考量项，且意大利水泥与预制混凝土产业成熟。

---

**2026-09-08 更新：第 2 条待办已有答案 —— BW Ideol Damping Pool，且成熟度远高于 Raijin Float**

09-05 建档时第 2 条待办问「Raijin Float 之外还有哪些混凝土浮体方案商」。2026-09-07 苏格兰政府经 HIE 拨款逾 **£778,000** 支持 **BW Ideol** 在 Ardersier 港建设 Damping Pool 混凝土浮体量产工厂的 **18 个月 FEED**，答案落地。

| 对比项 | Raijin Float（JB Energy） | **Damping Pool（BW Ideol）** |
|---|---|---|
| 成熟度 | 示范（巴西 18MW，尚未建成） | **已有 8 年运行样机 Floatgen（法国 SEM-REV，2MW，累计发电逾 40GWh）** |
| 产能状态 | 无 | **进入 500MW/年量产 FEED，单线每 12 天一座** |
| 公共资金 | 无 | **有（苏格兰政府 £778k，FEED 阶段）** |
| 目标市场 | 巴西等钢结构产能不足市场 | **苏格兰 —— 钢结构产能充足的成熟市场** |
| 承载标的 | 巴西 Aura Sul Wind 18MW 示范 | **Buchan 约 1GW，至多 70 座浮体** |

**这条推翻了本笔记 09-05 建档时的一个前提。** 原假设是「混凝土浮体适用于钢结构产能不足但水泥工业与船厂基础较好的新兴市场」。苏格兰不是这样的市场 —— **混凝土浮体在这里被推进的理由是本地就业与本地含量（1,200 + 2,900 个岗位），不是钢结构产能不足，也不是 LCOE。** 原判断不删，此处并列记入：

> **混凝土浮体的推广动力有两种，分别对应两类市场：新兴市场是「钢结构造不出来」，成熟市场是「产业政策要就业」。第二类比第一类量级大得多，且推进速度更快（公共资金直接介入 FEED）。**

**对我方的直接后果（已在 [[P1-英国Buchan 1GW漂浮式浮体先于整机锁定的应对]] 展开）：** Buchan 出现了本库首例**浮体先于整机锁定、且浮体方持有业主 33% 股权**的结构。本笔记第 1 条待办（接口兼容性判定）由此从「有则更好」升级为**入场券级别的前置条件**，并已带上明确期限（浮体 FEED 冻结约在 2028-03）。

**对意大利的含义未变但更强：** 意大利三个漂浮式标的（Renexia Sicilian Strait 2,793MW、Nereus HyMed 1,800MW、GreenIT-CIP 三项目 2,000MW）的浮体**尚未锁定** —— 这正是与 Buchan 相反的、我方还能带方案进去的窗口，且窗口不会一直开着。
