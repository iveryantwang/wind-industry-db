## 技术路径

**做法：额定功率锁死，只加大叶轮。**

以 2026-09-21 发布的 Vestas V182-7.2MW 为样本：

| 参数 | 数值 |
|---|---|
| 额定功率 | 7.2MW（与 V172-7.2MW 相同） |
| 叶轮 | 172m → **182m** |
| 比功率 | **277 W/m²** |
| 年发电量 | **+6%（上限）** |
| 容量系数 | **+2%（上限）** |
| 捕获电价 | **+3%（上限）** |

叶轮扫风面积按 (182/172)² 增加约 **11.9%**，额定功率不变，因此额定风速下移，功率曲线在中低风段整体抬高。

## 为什么这条路径在 2026 年变得重要

**三个市场条件同时成立，才使「不加额定功率」成为优势而非保守：**

1. **并网容量是稀缺资源。** 额定功率不变 → 并网协议、许可容量、升压站与出线不变。在英国（[[Nordex-英国电网接入公开表态]]）、德国、荷兰这类并网排队严重的市场，这等于**免去了项目最长的一段前置周期**。
2. **收益从「发多少」转向「什么时候发」。** 补贴退坡后项目按市场电价结算（[[意大利FERX陆上风电执行价与payasbid报价结构]]、[[德国陆上招标均价降至4.79分每度的整机报价含义]]），低风速时段电价通常更高、弃电更少，出力前移直接抬高实际收入。
3. **存量管道换型摩擦极低。** 塔筒、基础、吊装与运输方案大体沿用，叶片变长是主要变量。已获许可未开工的项目可以低成本换型。

## 对我方（整机厂）的含义

**这是一条必须跟进的路线，跟进难度不在气动，在三件工程约束：**

| 约束 | 说明 |
|---|---|
| **叶片长度与运输** | 182m 叶轮 ≈ 89m 级叶片。山地、弯道、桥隧受限场址需要分段叶片方案 —— 本库 [[分段叶片与山地偏远场址的机型准入]] 已记录这条约束 |
| **载荷与塔筒** | 扫风面积 +12% 而额定功率不变，极限载荷与疲劳载荷上升，塔筒与基础需重新校核，尤其在高轮毂高度组合下（参见 [[混凝土钢混合塔在190米以上轮毂高度的竞争含义]]） |
| **认证与标定口径** | 「捕获电价 +3%」这类指标需要有第三方可复核的测算方法，否则在投标文件里不成立 |

### 必须立刻补齐的一项能力：捕获电价测算

**产品差距可以排期，文档差距不能。** Vestas 已把捕获电价写进机型发布稿，这个指标会在数月内进入开发商的标准评标表。我方投标文件若只提供 AEP 与容量系数，在同一张评分表上会直接缺项失分。

**建议动作：** 建立一套按目标市场日前电价曲线 × 机型功率曲线的捕获电价测算模板，先覆盖意大利、德国、澳大利亚三个已在库且电价波动大的市场。**这件事不依赖任何新产品，本月即可完成。**
