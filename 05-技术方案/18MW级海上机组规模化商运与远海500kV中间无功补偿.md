# 18MW 级海上机组规模化商运与远海 500kV 中间无功补偿

## 要点

| 参数 | 数值 |
|---|---|
| 单机 | 18MW，叶轮 292m，扫风约 6.6 万 m² |
| 批量 | 33 台（全场 131 台中） |
| 单台年发电 | 最高约 5,600 万 kWh（等效约 3,100 h） |
| 离岸 / 水深 | 最远 81km / 最深 53m |
| 送出 | 500kV 交流 + **海上中间无功补偿站**（国内首座） |

## 技术含义

1. **18MW 从「样机」进入「批量商运」**：33 台同场运行，意味着 2027 年起将有可引用的批量可利用率与故障率数据。海外海上招标的资格审查（尤其亚太、中东、拉美）越来越看「同型号批量运行小时」，这是中国对手的新筹码。
2. **远距离交流送出的替代方案**：81km 未上柔直，而是以中间无功补偿站延长交流送出距离 —— 对越南、菲律宾等尚无柔直供应链的新兴海上市场，这是更便宜的参考方案，整机侧需配合的无功/电压控制能力要求随之提高。
3. **混装布置**：131 台中仅 33 台为 18MW，其余为较小机型 —— 同一场址混装大小机型的布置与载荷校核已被验证可行。

## 对我方

我方海上大兆瓦平台对外宣传若仍以「样机运行」为主，在与中国对手同台时证据等级已落后一档。建议在海外标书中补充「并网电压/无功支撑」能力说明，以对应远距离交流送出场景。
