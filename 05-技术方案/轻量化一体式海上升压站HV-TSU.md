## 方案要点

2026-08-18，西门子能源宣布其 **HV-TSU（High-Voltage TranSwitch Unit）**首次在海上风电项目投用 —— 安装于**中国国电唐山乐亭月坨岛海上风电场（一期，总装机 304MW）**。

| 参数 | 数值 |
|---|---|
| 升压站容量 | **300MW** |
| 上部组块尺寸 | **45m（长）× 38m（宽）× 23m（高）** |
| 上部组块重量 | **约 1,700 吨** |
| 建造方 | **振华重工（ZPMC）** —— 上部组块 + 导管架基础 + 基础插桩 |
| 风电场装机 | 304MW（一期） |

技术路径：把高压核心部件（开关、变压接口等）集成进单一紧凑单元，**以集成度换取上部组块重量下降**，同时保持海上环境下的可靠性要求。

## 为什么对我方（整机厂）有意义

**升压站不是整机厂的产品，但它是整机厂做「全链条方案」时绕不开的界面。**

1. **1,700 吨 / 300MW 是一个可用的基准值。** 本库 [[海上风电HVDC送出平台]] 记录的是 GW 级 HVDC 平台（万吨级），此前缺少交流小容量升压站的重量参照。**在 300MW 级以下的市场（越南近海、菲律宾 GEA5、柬埔寨、意大利部分海域），1,700 吨的上部组块意味着不需要 Sleipnir、Thialf 一类超大型起重船，普通浮吊即可完成**——这直接改变这些市场的送出成本模型。

2. **对 [[整机出海从设备供货到全链条方案]] 是一条正面证据。** 我方若在东南亚、中亚市场提供「整机 + 送出方案」的打包，轻量化升压站是使总包报价可落地的关键部件之一。**建议把 HV-TSU 一类紧凑型升压站纳入我方总包方案的可选供应链，而非默认沿用欧洲重型方案。**

3. **首台落在中国、由 ZPMC 建造，说明中国供应链已能承接该类集成产品的制造。** 这与 [[南欧XXL单桩本地化产能11米直径105米]]、[[大直径单桩量产产能年200支节奏]] 呈现的方向一致：**海上送出侧的制造成本优势正在向中国集中，而技术授权仍在欧洲厂商手中。** 我方做海外总包时，「欧洲技术 + 中国制造」的组合是当前成本最优解，但须提前核对目标市场的原产地与本地含量条款（参见 [[产能出海的市场准入前置条件]]）。
