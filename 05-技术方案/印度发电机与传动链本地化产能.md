## 方案概述

Flender 在印度新增一处风电**发电机**生产基地，含**一体化绕线工序**，定位为供应链本地化 + 产能扩张 + 贴近客户。Flender 在印度已有齿轮箱、联轴器与传动链服务业务，本次补齐发电机环节。

厂址与产能未由官方披露；印度本地媒体口径为钦奈、挂 Winergy 品牌，单一来源，本库不作结论。

## 为什么这对我方是一个技术方案问题，而不只是行业新闻

印度市场对我方的硬约束是 **ALMM（Wind）/ RLMM 名录准入**，而名录背后是本地含量核算。本地含量的计分逻辑里，**大部件的产地权重远高于紧固件、线缆一类的小件**，其中发电机、齿轮箱、叶片、塔筒是四个主要项。塔筒与叶片在印度有成熟本地供应；发电机与齿轮箱此前是短板。Flender 补上发电机后，**印度本地含量的可达上限提高了**。

这对我方意味着一条可能的合规路径：

```
我方机型 + Flender 印度发电机 + 印度本地叶片/塔筒 → 本地含量达标 → 进 ALMM/RLMM → 可投 ISTS 招标
```

## 这条路径成立的三个前提（按查证优先级）

| 序 | 前提 | 若为「否」的后果 |
|---|---|---|
| 1 | Flender 印度发电机产线**对外部整机厂开放供货**，非专供某一客户 | 路径直接不成立 |
| 2 | 该产线产品**已取得印度本地含量认定**（而非仅在印度组装） | 计分不认，路径无效 |
| 3 | 我方主力机型的发电机规格**与 Flender 印度产线的型谱兼容**（功率等级、绕线方案、接口） | 需重新设计，周期不可控 |

**第 3 项是纯技术判断，可由技术口在一周内自查完成，不依赖外部信息 —— 应先做这一项。** 若我方机型的发电机方案与 Flender 型谱根本不兼容，前两项就不必查了。

## 与既有判断的关系

本条不改变 [[P2-印度市场ALMM准入前置判定]] 的结论（印度准入仍是前置门槛），但它**给出了一条此前没有的补足手段**。此前的判断隐含假设是「本地含量只能靠自建产能」，Flender 的动作说明也可以靠**采购本地化的大部件**达成，投入量级差一个数量级。

三条在跑的印度标的（NTPC 600MW、Terra Clean 200MW、NLC 200MW）都卡在准入上，本条若成立，是三条共用的解法。
