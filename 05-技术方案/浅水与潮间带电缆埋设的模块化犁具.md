## 方案要点

| 项 | 参数 |
|---|---|
| 类型 | 表面供水（surface-fed）射流式埋设犁 |
| 作业环境 | **陆上与水下两用** |
| 埋深 | 海床下**最深 5 米** |
| 运输 | **模块化，可拆为集装箱**，便于快速转场与动员 |
| 适配 | 可更换**剑具（swords）** 与**压深器（depressor）**，适配不同埋深与缆型 |
| 重量控制 | 表面供水系统降低整机重量，保留向深水升级的余地 |
| 交付 | 2026 年底；2027 年投入商业作业 |
| 建造周期 | 早于约定的 96 周完成 |

## 为什么这一项对整机厂有意义

**整机厂不采购埋设设备，但整机厂要在近岸项目上报出可交付的工期与并网日期 —— 而近岸项目的工期失控点，往往不在风机，在登陆段与浅水段的电缆敷设。**

传统分工是：深水段用深水埋设机，浅水与登陆段另动员一套陆上或两栖设备。**两次动员意味着两个窗口期、两套天气风险、两份待机费用**，且两段的交界处常出现埋深不达标的返工。

「陆水两用 + 集装箱化 + 5 米埋深」这套组合把两段合并成一次动员。对整机厂的直接影响有两条：

1. **报价时的并网日期可信度提高。** 近岸项目的 COD 风险从「取决于能否协调到两套设备」变成「取决于一套设备的档期」。
2. **小市场的可达性提高。** 集装箱化意味着设备能进入没有专业海工基地的市场 —— 这恰好是我方最有机会的那一类市场（东南亚近岸、中亚内陆）。
