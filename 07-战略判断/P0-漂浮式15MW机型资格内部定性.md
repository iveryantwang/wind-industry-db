## 为什么这条要单列，而且是 P0

**这是本库第一条「对手方是我方自己」的战略判断。**

同一个问题 —— **我方有没有 15MW 级漂浮式适配机型** —— 在 2026-08-05 的 [[P1-英国Llyr漂浮式示范整机窗口]] 复核中首次提出，随后发现它同时是另外两条线的前置条件。三条线各自把它挂成自己的待办，结果是**三条都在等同一个答复，而这个答复没有明确的责任人和期限**。

| 被卡住的线 | 标的容量 | 15MW 级门槛来源 |
|---|---|---|
| [[P1-英国Llyr漂浮式示范整机窗口]] | 200MW | 单机 12.5–16.7MW（每场 100MW / 6–8 台） |
| [[P1-意大利漂浮式管道提前布局]] | 13,588MW | HyMed 已锁 15MW 档；Renexia 等 5 家管道普遍对标 15MW+ |
| [[英国-Seatrium-TwinHub漂浮式32MW]] | 32MW | 英国漂浮式管道整体已站在 15MW 级 |
| **合计** | **约 13.8GW** | |

**三条线合计约 13.8GW 的标的，全部无法推进，只因为一个内部问题挂了 3 天。** 这不是外部窗口紧迫，是内部流程本身成了瓶颈 —— **按本库 P0 的定义（行动窗口 4 周内关闭），本条符合，且比多数外部 P0 更可控。**

## 2026-08-07 的新变量：竞对已经把这道题做完了

**明阳智能 CNOOC Anlan 于 2026-08-07 商业投运** —— 16MW（MySE 16-260）、张力腿平台（TLP）、水深 136m、离岸 136km、50 年一遇抗台设计、整机码头总装一次性拖航、年发电 54GWh。详见 [[明阳智能-CNOOC Anlan 16MW张力腿漂浮式投运]] 与 [[张力腿平台TLP漂浮式整机码头总装一次拖航]]。

**加上此前的 OceanX 16.6MW 双机半潜平台，明阳现在同时拥有半潜与 TLP 两种浮体形式的 16MW 级在运实绩。**

**这改变了问题的性质：**

- 此前：「我方有没有机型」是一个影响商务节奏的问题 —— 没有可以慢慢补
- 现在：漂浮式项目的技术预选，业主的第一个问题是「你有多少台漂浮式机组在运行、在什么水深」。**竞对能回答，我方不能回答。这一条就足以在技术预选阶段被筛掉，商务努力无法弥补**

## 需要的答复内容（一页，不要长）

1. **有无通过浮体—塔筒耦合载荷校核的 15MW 级漂浮式版本？** —— 不是陆上/固定式 15MW 平台，是漂浮式版本
2. **若有：** 可对外披露的运行小时数、型式认证状态（DNV / 中国船级社 / 其他）、已完成的浮体形式（半潜 / TLP / Spar）、可适配的水深区间
3. **若无：** 样机计划的时间表与预算是否已立项；从立项到可对外披露实绩需要多久
4. **附加：** 我方现有海上机型对「码头总装 + 整体拖航」工艺的适配性 —— 这一条与浮体形式无关，是可独立复用的能力（见 [[海上风电安装船与港口能力瓶颈]]）

## 三种答复对应的处置

| 答复 | 处置 |
|---|---|
| **有，且有在运实绩** | 三条线全部按原计划推进；同步准备与明阳的技术对标材料 |
| **有，但无在运实绩（仅设计/样机）** | 三条线降级为「技术预选阶段参与，不承诺交付期」；优先争取示范项目（政治敏感度低、对实绩要求相对宽松），[[英国-Cierco-Llyr漂浮式2x100MW]] 与 [[英国-Seatrium-TwinHub漂浮式32MW]] 属此类 |
| **无，且无样机计划** | 三条线 `status` 全部改 `已放弃`；漂浮式转为技术标尺跟踪（见 [[英国漂浮式2050年40GW产业化路径]]）；资源转投确定性更高的陆上市场 —— 意大利 FER X 的 16.5GW 陆上配额（见 [[意大利-FER2法令与漂浮式执行价调整]] 2026-08-08 补录）是现成的去处 |

**第三种答复不是坏结果。** 明确放弃比在三条线上各投入一点、各拖三个月要好得多 —— **拿不出对位机型就去做技术交流，会在业主与 SBM Offshore 这类油气系采购体系处留下负面档案，漂浮式圈子小，第一印象很难修。**
