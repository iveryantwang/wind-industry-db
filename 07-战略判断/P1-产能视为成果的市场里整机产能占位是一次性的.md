## 判断

**本库过去把「产能出海」当成一个统一决策来评估，这是错的。市场要先分两类，两类的决策逻辑相反。**

| | 视外资整机产能为**安全风险** | 视外资整机产能为**产业成果** |
|---|---|---|
| 典型 | 英国、欧盟、美国、日本、台湾 | **埃及、哈萨克斯坦、越南、部分东南亚与中亚** |
| 是否有来源国安全审查 | 有（英国 NSI、欧盟 FSR、美国 IRA 关联实体） | 无 |
| 本国是否已有整机产能 | 有 —— 外资产能＝与本土产业竞争 | 无 —— 外资产能＝填补空白 |
| 对手方 | 监管机构（审批者） | 国家电力公司／可再生能源署／主权基金（受益者） |
| **正确决策顺序** | **准入确定性 → 订单可见度 → 产能投资** | **产能承诺本身就是入场券，先到先得** |
| 样本 | 明阳 Ardersier £15 亿被否，机组一并禁入 | 三一埃及 2GW 厂＋2GW 项目；三一哈国 Shu 厂 2GW 已投产 |

完整机理见 [[产能出海的市场准入前置条件]] 的 2026-09-07 更新段。

## 为什么是 P1 而不是 P2

**因为第二类市场的占位是一次性的。**

一个国家通常只需要一到两座整机厂。这与订单不同 —— 订单每年都有新的，产能位置只有一个。**先落地的厂商不是"领先"，是把后来者的资格一并拿走了**：后续项目的本地含量要求会自然向已有的本地产能倾斜，这甚至不需要政策歧视，只需要「优先采购本地制造」这一条通行规则。

已发生的占位：

| 国家 | 占位方 | 状态 |
|---|---|---|
| 哈萨克斯坦 | **三一重能**（与 Samruk-Kazyna 合资 Shu 厂，2GW/年） | **已投产 —— 位置已失** |
| 埃及 | **三一重能**（2GW/年厂 ＋ 苏伊士湾 2GW 项目打包，对手方 EETC ＋ NREA） | **在谈，最终协议未证实已签** |
| 越南 | 未见整机产能协议 | **尚未被占位** |
| 柬埔寨、老挝 | 市场规模不足以支撑独立整机产能 | 不适用（应看区域性产能覆盖） |

**推进速度参照：中国同行大致以每年一到两个国家的节奏在推进第二类市场的产能占位。按此节奏，越南是本库五国里唯一还开着的门，且不会开很久。**

## 为什么 deadline 设在 10-31 而不是更早

本条的产出不是一笔交易，是一份**判定表 + 越南可行性评估**。这是内部动作，不依赖外部窗口，但需要跨部门（市场、产能规划、投资）协同，一个月是合理下限。

**同时须诚实记录：本条的执行难度远高于本库其他判断。** 前述条目多为「建立接触、提交技术输入」，本条涉及产能投资承诺 —— 决策层级更高、可逆性更差。**若判定后结论是我方不具备做产能承诺的条件，本条应改 `已放弃` 并明确记录理由，而不是长期挂着。** 结论为「不做」也是有价值的产出，因为它同时意味着第二类市场对我方实质关闭，资源应全部转向第一类。

## 建议行动

1. **本月内**：把本库覆盖的全部市场按上表两分，输出一份判定表（含判据逐项打分）
2. **本月内**：对越南做单独评估 —— 我方以 EVN 或工贸部为对手方提出产能协议的可行性、最低承诺规模、以及与既有的 [[P1-越南Decree272后前期技术卡位]] 等三条判断如何衔接
3. **并行核实**：三一与埃及 EETC/NREA 的最终协议是否已签署（见 [[三一重能-埃及2GW项目与年产2GW整机工厂]] 待办）—— 若未签，埃及尚有变数
4. **一并复核**：[[P0-哈萨克斯坦本地产能门槛应对]] 应据本条重写 —— 该条此前把 Shu 工厂当成一个需要应对的门槛，按本条框架它其实是**位置已失的既成事实**，应对方向从「跨越门槛」改为「评估是否还有第二座厂的空间」

## 风险与反面意见

**本条最大的风险是把两个样本（埃及、哈国）当成规律。** 两例都是三一，都在中亚／北非，都以国家机构为对手方 —— 样本同质性高，可能只反映三一一家的打法，而非市场普遍规律。

**反面情形也真实存在：产能承诺一旦落地，若订单未如期而至，产能利用率风险由我方独担。** 本条原始条目 [[产能出海的市场准入前置条件]] 提出的四项校验（安全审查、本地含量中立性、订单管道可见度、政府书面承诺）在第二类市场同样适用，**只是顺序从「先校验再投」变成了「边谈边校验」** —— 这本身就是更高的风险。

**因此本条的产出应当包含「不做」这个选项，且给它同等的分析权重。**
