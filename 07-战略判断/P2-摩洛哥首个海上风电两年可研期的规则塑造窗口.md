## 判断

**这是一条「低成本、长周期、不可逆」的判断 —— 优先级低，但不做的代价在两年后才显现，且到时无法补救。**

### 为什么是 P2

按口径，P2 = 持续观察。摩洛哥整机定标最早在 2028 年，不存在 4 周或本月内的窗口，**不能占用本季度的商务资源**。定 P0 或 P1 会挤压埃及、五国与英国的执行力。

### 但为什么必须现在建条目而不是等 2028

**因为要影响的东西现在就在被写。**

可研范围里的四项直接决定我方两年后的投标资格：

| 可研条目 | 决定什么 | 定稿后能否改 |
|---|---|---|
| 风电场概念设计 | 单机容量假设、水深与基础型式区间 | **否** |
| 港口与物流 | 索维拉等港口吊装能力 → 机型物理上限 | **否** |
| 监管框架 | 认证体系、许可制度、本地含量口径 | **否** |
| 市场与供应链 | 供应商可达性评估 → 谁被视为合格来源 | **否** |

**在零存量市场，可研文本就是规则的母本。** 摩洛哥没有一台海上风机，没有海上风电法，没有并网规范 —— 这些全部是空白，两年内被填上，两年后招标直接抄。

### 结构性风险：参照系是欧洲的

出资方 EIB、牵头方德国总部的 OWC（Aqualis）。**认证要求、供应链尽调口径、E&S 条款的默认写法会是欧洲体系。** 这不是排斥，是路径依赖 —— 但结果一样：**若我方主力海上机型没有 IEC / DNV 型式认证与可核验的欧洲项目业绩，两年后要补的不是价格，是资质，而资质补不了那么快。**

这与库内 [[产能出海的市场准入前置条件]]、[[P2-中国同行产能出海与地缘准入风险]] 是同一条逻辑的又一次出现。

### 与埃及的动作差异（这是本条最需要记住的一点）

同为中东非，两地要做的事完全相反：

| | 埃及 Ras Shokeir 1GW | 摩洛哥 Essaouira 1GW |
|---|---|---|
| 阶段 | **PPA 已签，整机将定** | 可研启动，规则待写 |
| 时间尺度 | **6–12 个月** | 24+ 个月 |
| 需要的动作 | **抢渠道、找代理、接触业主** | **进咨询链条、提交技术参数** |
| 需要的资源 | 商务 + 人 | 技术文档 |
| 优先级 | **P0** | **P2** |

**把两者混为「中东非机会」是错的 —— 用埃及的打法做摩洛哥会浪费资源，用摩洛哥的打法做埃及会错过窗口。**

### 时间表可靠性打折的依据

EIB 的技术援助招标在 2024-07 被取消后重启，项目整体推迟约两年。**该项目有滑期先例，2029 开工目标应按乐观值看待。** 这进一步支持 P2 而非更高优先级。

## 行动（全部为低成本技术动作）

1. **摸清 OWC / Aqualis 在可研阶段的厂商访谈机制**（其在英、法、德均有海上风电团队；我方若在欧洲有既往接触可循此路径）
2. **准备一份摩洛哥专用的海上机型参数包**：适用水深区间、单机容量档位、运输与吊装要求、港口起重能力需求 —— 用于概念设计与港口物流两章的输入
3. **核对我方主力海上机型的 IEC / DNV 型式认证状态**，明确在欧洲参照系下的资质缺口，两年内补齐
4. **每季度复核一次**（不必每日），跟踪：① 可研进度与阶段性成果发布；② EIB 是否进入建设期贷款角色；③ 首期是走固定式还是漂浮式
