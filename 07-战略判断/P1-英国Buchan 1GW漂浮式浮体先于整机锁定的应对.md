## 为什么这条要单独立判断

本库现有的英国漂浮式判断（[[P1-英国Bellrock 1.8GW漂浮式早期技术卡位]]、[[P1-英国Llyr漂浮式示范整机窗口]]、[[P1-凯尔特海漂浮式1.73GW市场包统一打法]]）都建立在同一个隐含前提上：**整机与浮体大致同期选型，我方可以拿整机去争取，浮体后配。**

**Buchan 打破了这个前提。**

| 项 | Buchan 的情况 |
|---|---|
| 浮体 | **已定** —— BW Ideol Damping Pool，混凝土，至多 70 座，苏格兰本地制造 |
| 浮体方身份 | **同时是业主股东（33%）** |
| 浮体产能 | 2026-09-07 已获苏格兰政府 £778k 支持进入 **18 个月 FEED**，规划 500MW/年 |
| 整机 | **未定** |

**顺序反了：不是整机厂带浮体去投标，是浮体方带业主来选整机。**

## 时间轴（两个窗口，早的那个才是真的）

| 节点 | 时间 | 性质 |
|---|---|---|
| **浮体 FEED 期** | 2026-09 → **约 2028-03** | **技术接口冻结窗口 —— 我方的真实窗口** |
| 整机定标 | 约 2027 底 – 2028 年（FID 前 12–18 个月） | 商务窗口，届时技术条件已定 |
| FID | 2029 | |
| 投运 | 2033 | |

**在 FEED 冻结之后进场，我方能谈的只有价格；在 FEED 期内进场，我方能影响塔底接口、重量上限、总装与拖航方案。**

## 建议行动（按顺序）

1. **技术口两周内出具兼容性判定**：我方 14MW 级以上海上机型与预应力混凝土半潜浮体（Damping Pool 构型）的塔底法兰接口、机舱—塔架总重上限、码头总装一次拖航工艺是否存在结构性不兼容。有不兼容项就列清单与改造成本
2. **对接口选 BW Ideol 法国实体，不选业主。** 它是本项目里唯一同时管技术方案与持有股权的一方；BayWa r.e. 与 Elicio 都不是浮体技术方
3. **接触口径用「整机 + 浮体耦合设计输入」，不用「整机报价」。** FEED 阶段对方要的是载荷与接口数据，不是价格
4. **同步核实**：Ardersier 工厂 500MW/年产能对应 1GW 项目需 2 年浮体供应期，我方需匹配的连续交付能力与港口吞吐约束（见 [[漂浮式整机码头总装的港口吞吐约束]]）
5. **把「浮体是否已锁定」加入本库全部漂浮式标的的筛选维度**，重排苏格兰漂浮式接触优先序 —— 浮体未锁定的（Bellrock）优先级应高于已锁定的（Buchan），因为前者我方还能带方案

## 与既有判断的关系

**这条同时修正 [[P1-英国本地含量劣势对冲]] 的一个假设。** 该条把英国本地含量劣势理解为「产能与就业承诺不足」。Buchan 显示的是更前置的一层：**苏格兰的本地含量已经通过公共资金锁进了浮体环节，且在 FEED 阶段就完成。** 我方即便后续承诺产能，也补不上一个已经被别人在 FEED 期占掉的位置。

**对意大利同样成立** —— 见 [[P1-意大利漂浮式管道提前布局]] 的 2026-09-08 更新段：意大利三个漂浮式标的的浮体尚未锁定，这正是与 Buchan 相反、我方还能进的窗口。
