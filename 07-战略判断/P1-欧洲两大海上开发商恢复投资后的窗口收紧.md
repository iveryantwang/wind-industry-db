## 判断依据

### 触发事实（均为 2026-08-13）

| 主体 | 事实 |
|---|---|
| Ørsted | Q2 EBITDA（剔除新合作与取消费）54.4 亿 DKK，高于预期 51 亿；维持全年 >280 亿 DKK 与 500–550 亿 DKK 投资指引；按计划恢复分红；CEO Errboe：有稳健度追求海上风电新机会 |
| Ørsted | 对德国 **2.5GW 北海 CfD 招标**结构表示「非常满意」 |
| RWE | 上半年风电业务利润大增（reNEWS 口径，未取具体数字） |
| Ørsted | Revolution Wind 61/65 台已装，年内完工 —— 交付执行力恢复的佐证 |

**并列口径提示：** 同日另有报道称 Ørsted Q2 净利同比下滑约 79% 至约 1.06 亿美元。EBITDA 超预期与净利大跌可同时成立（减值与一次性项目影响），两个口径并列保留。

### 为什么这对整机厂是坏消息而不是好消息

1. **开发商回场 ≠ 采购机会增加。** Ørsted 与 RWE 的整机供应关系高度锁定：RWE Vanguard East/West 各 92 台 V236-15.0MW 已签 Vestas；Ørsted 的欧洲项目基本在 SGRE 与 Vestas 之间分配。它们回场，占掉的是**招标名额**，不是**供应商名额**
2. **CfD 兜底会削弱价格竞争力。** 德国两阶段 CfD 若定稿，项目现金流确定性上升，业主对整机价格敏感度下降、对技术确定性与工期权重上升 —— 这正是我方相对优势最弱的维度（见 [[德国-WindSeeG2026修正案双边CfD与运行期延长]]）
3. **低谷期是我方唯一的结构性窗口，现在正在关闭。** 2025–2026 欧洲开发商收缩期，中小开发商与新进入者曾是我方可谈的对象；两大玩家恢复出价能力后，中小开发商在招标中的胜率下降，我方的间接通道随之变窄

### 应转向哪里

| 方向 | 理由 |
|---|---|
| **意大利漂浮式** | 开发商结构分散（Renexia、Avenhexicon、GreenIT/CIP、Acciona），无单一主导者，且多数处环评中、整机全部未定 |
| **凯尔特海市场包 1.73GW** | 漂浮式，Ørsted/RWE 均非主导 |
| **土耳其 YEKA（2027Q1）** | 两大玩家尚未表态进入 |
| **越南 / 老挝 / 柬埔寨** | 欧洲两大玩家不参与，竞争面是中国同行而非 SGRE/Vestas |

## 具体动作

1. **8-31 前**：市场口更新欧洲海上在跟标的的「预计投标方」栏，把 Ørsted 加回德国 2.5GW 北海、荷兰 Gamma、英国 AR8 三处
2. **9-15 前**：据此产出一页资源再配置建议 —— 欧洲海上的投入是否应从「德国/荷兰主攻」改为「意大利漂浮式 + 凯尔特海主攻」
3. 本条**不推翻**任何既有 P0/P1，只调整权重；[[P1-荷兰Gamma招标标前绑定投标联合体]] 与 [[P0-德国WindSeeG修正案35年运行期机型校核]] 均照原计划执行
