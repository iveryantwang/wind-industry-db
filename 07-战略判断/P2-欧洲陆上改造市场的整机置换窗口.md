## 判断

**本库一直把欧洲陆上的整机机会挂在拍卖与许可上。Fortore 说明还有第二条入口，而且我方对它没有任何系统性的判断。**

### 触发本条的事实

2026-09-11 更正 [[意大利-IVPC-Fortore]] 时查到的一手信息（Eurus Energy 官网，署 2026-05-29）：

| 项 | 改造前 | 改造后 |
|---|---|---|
| 台数 | **140**（1996–1999 年建成） | **22** |
| 容量 | **84MW** | **134.2MW** |
| 单机 | 约 0.6MW | **6.1MW（GE Vernova）** |
| 融资 | — | **1.871 亿欧元**（UniCredit + Crédit Agricole Italia），2026-05-29 关闭 |

**台数减少 84%，容量增加 60%，整机订单 134.2MW。**

### 改造与新建的入口差异

| 维度 | 新建 | **改造** |
|---|---|---|
| 场址 | 需新取得 | **已有** |
| 并网容量 | 需竞争性分配 | **已有（且增容部分通常有简化路径）** |
| 环评 | 全程 | **简化或部分豁免** |
| 触发时点 | **拍卖日历 / 许可节奏** | **老机到寿（机龄决定）** |
| 决策人 | 开发商 + 融资方 | **存量资产业主本人** |
| 竞争集合 | 全部投标厂商 | **可适配既有场址边界与吊装条件的厂商** |

**最后一行是我方的机会与障碍所在：** 改造受既有场址边界、道路、吊装空间、机位间距与并网容量的约束，**能装进去的机型是被物理条件筛过一轮的**。这既缩小了竞争集合，也可能直接把我方排除在外 —— 取决于我方是否有适配的塔架高度与叶轮直径组合。

## 本库已有但从未串起来的改造样本

**这条线的证据本库其实一直在收，只是每条都当成孤立订单记了：**

| 条目 | 内容 |
|---|---|
| [[意大利-IVPC-Fortore]] | **140 台 → 22 台，84 → 134.2MW（本次更正后）** |
| [[Vestas-德国EuropeanEnergy Wulfshagen 50MW改造订单]] | 德国改造 50MW |
| [[Vestas-法国Montbeliard 22.5MW改造项目投运]] | 法国首个改造项目（ERG） |
| [[PNE出售德国两个合计45MW改造风场]] | 德国改造资产交易 |
| [[Vestas-韩国Yeongdeok改造EnVentus首批交付]] | 韩国改造（欧洲之外） |
| [[意大利-Enel-Campo Eolico Ariano 84MW]] | Enel 以 1.45 亿欧元收购 84MW 存量 |

**六条里 Vestas 占三条。** 这不是巧合 —— **改造项目的天然优势方是存量机组的原厂，因为它掌握机位数据、并网记录与业主关系。** 我方在欧洲没有存量，这是结构性劣势，必须在判断里写明而不是回避。

**但 Fortore 是个反例：老机不是 GE 的（1996–1999 年的 0.6MW 级机组），改造却由 GE 拿下。** 说明原厂优势并非不可破，**破口在于改造是一次完整的重新选型，而不是备件续购。**

## 为什么是 P2

**因为它没有一个会关闭的窗口，但它会改变资源分配。**

本条不针对任何单个标的，没有投标截止日，符合 P2「持续观察」。**但它与其他 P2 的差别在于：它要求的第一个动作是一份内部的市场图，而不是等外部信息。** 这一点与 [[P2-独立服务商侵蚀存量机组运维的应对]] 相同 —— 两条都是「现在就能做、只是没人做」的内部功课。

**并且两条指向同一批资产：欧洲的存量机组。** 一条讲它的运维收入正在被独立服务商拿走，一条讲它的置换订单正在被原厂和 GE 拿走。**合起来看，欧洲存量机组这个池子里发生的事，我方目前一件都没参与。**

## 与 09-09 结论的衔接

09-08 的 DNV 研究与 09-09 的 DWT 案例已经得出：**欧洲成熟市场比的是产线摊薄与在位优势，新兴市场比的是落地能力。**

**本条给欧洲那一侧补上第三个具体形态：** 除了产线摊薄（DNV）、服务在位（DWT），还有**存量置换**。三者的共同点是**都不是靠投标赢的**。

**含义要说直白：我方在欧洲陆上如果只准备投标能力，准备的是三分之一。**
